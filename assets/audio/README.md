# Mobile game audio

The three short OGG files used by the Android game come from Kenney's
**Impact Sounds 1.0** pack:

- `merge-pop.ogg` ← `impactGeneric_light_000.ogg`
- `merge-soft.ogg` ← `impactSoft_medium_000.ogg`
- `score-collect.ogg` ← `impactBell_heavy_004.ogg`

Official pack page:
`https://www.kenney.nl/assets/impact-sounds`

Kenney distributes the pack under Creative Commons Zero (CC0 1.0). The
original package license is retained as `KENNEY-IMPACT-SOUNDS-CC0.txt` and is
also copied into the APK's `assets/licenses/` directory.
