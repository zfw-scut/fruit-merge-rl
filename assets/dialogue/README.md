# AI 完整语料

本目录保存移动版 AI 角色的离线完整语料。每个 `txt` 文件对应一个明确事件语境，
每行都是由大模型预先完整构思、可以直接显示的一句话。游戏运行时只抽取整行，
不会拼接前缀、词槽、主体或结尾，也不会调用在线大模型接口。

角色口吻定位为“可爱但不幼稚的真人陪玩”：以自然短句和日常口语为主，允许适量
使用语气词、停顿和拟声词，让惊喜、犹豫与紧张听起来有情绪。避免“执行、目标、
方案、判断完成”等系统提示腔，也避免靠网络梗、连续感叹号或过度撒娇制造热闹。

当前每类固定 1024 条：

- `welcome.txt`：进入或继续 AI 模式时都成立的中性陪伴语；
- `thinking.txt`：AI 正在分析投放位置；
- `hesitating.txt`：候选位置接近、AI 正在犹豫；
- `ready.txt`：AI 已完成本手决策并选好位置；
- `happy.txt`：AI 刚刚完成至少一次水果合成并得分；
- `surprised.txt`：玩家完成值得惊讶的高等级合成或连锁；
- `worried.txt`：AI 场景接近危险线。

`android/app/build.gradle` 会在打包前检查每类至少 1000 行、逐行唯一、无空行和
控制字符，并把单句长度限制在 4～24 个 Unicode 字符，避免气泡里出现长篇文案。
`AiDialogueDirector` 使用无放回洗牌袋抽取完整句子；语料随机源与水果队列、
AI 手势和粒子随机源相互隔离。

修改语料后必须重新运行 `tools/generate_mobile_ui_font.py`，确保共享 Q 版位图字体
包含新增汉字，再执行 Android 构建。
