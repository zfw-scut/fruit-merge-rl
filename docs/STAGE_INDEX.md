## 当前阶段的相邻读取

- 模拟器、物理、场景实验室：S6；需要同源迁移原因时读 S5 的 `66`，再按需读 S4。
- 门户：S4 的 `61–62`、`65`；当前操作以 `PROJECT_PORTAL.md` 为准。
- 当前模型和评估：S4 的 `54–55`、`59–60`、`63–65`；效果以最新报告和比较矩阵为准。
- 辅助学习机制：先读当前专项设计；只有追溯演化时才进入 S3 的 `39–50`。
- Reward V2/V2.1：属于 S2 已完成实验，不是当前模型谱系的默认奖励。

## 维护规则

- 新实现记录继续写入当前 S6，直到出现明确的新项目目标或下一次不兼容契约。
- 建立新阶段时只更新本页和 `docs/README.md` 的当前阶段，不批量改写历史记录。
- 历史记录保留当时事实；修正当前理解时在新阶段记录覆盖关系，不把旧记录重新包装成当前说明。
