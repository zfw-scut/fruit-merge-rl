# 启动18M探索与bonus影子诊断训练

## 实验目的与归因边界

本轮采用方案三：保持首轮辅助动作模型的实际策略、辅助监督、主动学习bonus=1和其余训练
设置不变，只把epsilon到达0.05的时间从6.4M延后到18M，并旁路计算bonus
`0.5/1/2/4/8`的候选动作。影子动作不执行、不进入Replay且不消耗随机数，因此本轮训练
效果变化主要用于检验epsilon日程；bonus数据只用于训练完成后的量纲诊断和下一轮决策。

训练loss、吞吐或单个实时窗口分数不视为策略提升。最终判断仍需使用相同seed与预算的
4096局30/120 FPS评估、高等级合成分布，并与首轮辅助动作模型和5层Fast基线比较。

部署代码为`baseline-scale-v1`分支提交`0e9c1da`，通过Git bundle快进同步到克隆服务器。

## 启动和首批训练事实

正式任务于2026-08-09启动。达到887,296 transition时：

- 更新2442次，epsilon为0.95317；
- 端到端吞吐约2486.64 transition/s；
- GPU采样利用率67%，进程显存约11,339 MiB，无OOM、NaN或异常退出；
- 总loss 0.04327，DQN loss 0.02573，辅助原始loss 0.35082；
- bootstrap实际激活比例0.79995，与0.8配置一致；
- 实际主动学习及其有效改变率均为0，符合高epsilon阶段设计；
- bonus 0.5/1/2/4/8的影子动作改变率分别约8.21%、15.49%、27.81%、44.37%、
  60.86%；
- bonus=1发生改变时，平均Q代价约0.00215，平均不确定性增益约0.00432。

`【观察】` 首批影子数据随bonus单调拉开，足以支持后续量纲判断；这只是早期随机性较高且
模型快速变化阶段的单个窗口，不能提前据此选择bonus。应在18M以后结合分位数、时间趋势、
贪心重叠率和最终策略评估统一决策。

面板曲线快照已生成，首个快照使用25个指标窗口并覆盖到861,184 transition。本机通过
隐藏SSH隧道访问`http://127.0.0.1:8765/`。
