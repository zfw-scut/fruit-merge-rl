# 让场景水果自动自然落稳

## 修改原因

场景实验室原本把鼠标放置的位置直接当作静态状态，水果会悬浮在空中。编辑体验与游戏
物理不一致，也容易让后续21动作评估从不自然状态开始。

## 本次修改

- 为 `TensorVectorSimulator` 新增 `settle()`：不投放水果，只把当前场景推进到稳定、终局
  或单次等待上限；不会消费队列或增加决策步数。
- CPU 回退的正常 `step()` 与 `settle()` 共用同一段稳定推进逻辑，避免维护两套物理。
- 场景服务新增 `/api/settle`。编辑时使用单环境 CPU 物理，不改变训练或21动作 CUDA 热路径。
- 放置水果和拖动结束后自动整理；异步结果通过场景快照和请求序号防止覆盖较新的编辑。
- 自动整理固定采用30 FPS降低等待；手动整理仍可按页面选择运行30或120 FPS。
- 新放置水果使用投放物理半径，合成后的结果继续保留模拟器返回的实际物理半径。

## 验证

- 新增模拟器契约测试，确认水果会下落，同时队列和 `step_count` 不变。
- 新增场景服务测试，确认默认120 FPS页面请求会走30 FPS快速整理并返回稳定水果。
- Python文件通过编译检查，内嵌前端脚本通过 Node 语法检查。
- 浏览器实测：樱桃从点击位置 `y≈306` 在约0.89秒内稳定到地面 `y=1080`。

## 旧分支边界

旧分支只读搜索未发现适用的无投放稳定公共接口。本次实现复用当前 Tensor 物理，不迁移
旧观看器稳定门、旧 HeadlessGame 或其它运行依赖。
