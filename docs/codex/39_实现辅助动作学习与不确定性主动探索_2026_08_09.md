# 实现辅助动作学习与不确定性主动探索

## 修改原因

在继续开发行为段反事实归因前，先让当前模型直接学习一次实际投放的物理效果，并通过
多个策略头的 bootstrap 分歧提供决策不确定性。该能力必须留在 GPU 热路径，不能把每步
数据先转交 CPU，也不能用未执行动作伪造监督。

## 实现范围

- CPU Tensor 与 CUDA 单 Kernel 模拟器增加固定大小动作效果事件：q0 最早接触多标签、
  主接触信息、q0 谱系深度和最终后代槽位；
- 复用定长合成事件，按全局时间顺序提取前三个新生成水果，不限制 q0 谱系；
- 把合成、q0、首次接触、新水果、最终后代、稳定和风险标签压缩后写入 GPU Replay；
- Replay 在 transition 首次写入时生成并固化 bootstrap mask，保证至少一个策略头有效；
- 模型共享 GNN 和动作探针，增加多个同构 Dueling 策略头，兼容输出取各头均值；
- learner 按头计算 Double DQN target 和 mask 后 Huber loss；
- 辅助头只 gather 实际执行动作，按五个 loss 分组训练；
- 低 epsilon 时在既有 epsilon 探索预算内，用均值 Q 加策略分歧选择部分高不确定动作；
- 训练面板增加辅助 loss、策略头分歧、主动学习比例和高等级水果生成密度；
- 评估输出各等级生成/消除总数及每千次投放密度，训练曲线扩为 3×2；
- 新增 24M 云端配置与确定性合成数据预览图。

## 兼容边界

`policy_head_count=1`、`action_effect_enabled=false`、
`active_learning_enabled=false` 是默认值。因此历史 TOML 仍运行原单头、无辅助 loss 的
训练，旧 checkpoint 参数名也保持不变。新配置启用新增参数，属于新一代模型训练，不把
新增随机头误写成旧 checkpoint 的等价续训。

关键决策采集器没有成为密集辅助监督的依赖。每条实际 transition 的辅助标签直接进入
Replay；未来反事实多动作推演、稀有事件和行为段归因继续使用独立事实/派生监督框架。

## 性能边界

- CUDA 只增加每环境固定大小累计字段，没有逐帧 Python 事件或 CPU 同步；
- 标签压缩、Replay、前向、loss 和主动探索全部在当前设备执行；
- 主动学习不增加 epsilon 总探索率；
- 5 个策略头和辅助 Replay 会增加 learner 算力与显存，云端正式训练前必须重新测吞吐、
  batch 与活跃环境数，不能套用历史单头性能结论；
- 面板绘图仍由低优先级旁路读取 JSONL，训练进程不导入 Matplotlib。

## 证据边界

本次测试证明训练链路和 CUDA 契约可运行，不证明策略效果提升。预览图片明确使用合成
数据，只用于评价面板布局。正式大规模训练完成后，必须新增模型报告并更新
`model_evaluations/COMPARISON_MATRIX.md`，区分训练事实、评估观察、原因假设与采用决策。
