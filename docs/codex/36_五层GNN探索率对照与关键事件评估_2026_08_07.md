# 5 层 GNN 探索率对照与关键事件评估

## 本次变更

- DQN 配置支持按 transition 定义分段线性 epsilon，并兼容既有线性衰减配置；
- 新增两组等训练量的 5 层 GNN 配置，固定除 epsilon 外的全部实验条件；
- 最终评估在 GPU 上累计每局各等级合成、高阶水果生成/消除、历史峰值与终局等级分布；
- 保存由显式 seed、动作和逐步分数变化组成的紧凑回放索引；
- 按关键事件和分数区间选取代表局，进行第二遍动作锁定回放并保存状态、Q 值和事件；
- 新增 30/120 FPS 分数密度和高等级事件标准图，并接入面板；
- 新增两轮串行训练编排与训练结束后的只读面板服务。

## 性能边界

训练热路径未加入逐局日志、逐步 CPU 拷贝或绘图。关键事件统计只发生在隔离的 greedy
评估中，且第一遍仅保存紧凑 Tensor；体积较大的状态轨迹只对最多 128 个分层样本进行
第二遍回放。云端仍需先以目标 GPU 实测 5 层模型的安全 batch，再启动两组正式训练。
