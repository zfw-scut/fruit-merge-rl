# 实现状态相关无合成参考奖励

## 修改原因

首轮 `spatial_v2` 使用与状态和动作无关的空场平均水果占用补偿。训练末期该补偿约为
原始空间变化绝对值的6.5倍，正奖励率达到98.03%；自定义场景中也出现无合成且形成突出位
仍获得明显正奖励的情况。需要消除固定补偿对奖励基线的系统性抬高。

## 新增与保留

- 新增 `spatial_v2_1`，把当前状态21个无合成幽灵投放中的最小空间损失作为参考；
- 幽灵投放与三个未来队列位的21列几何全部使用定长Tensor批量计算，不运行21次真实物理；
- 相邻决策状态继续缓存势能和参考损失，空场reset通过动作表查值恢复；
- 训练面板和场景实验室改为显示“无合成参考损失”与参考动作；
- 保留原 `spatial_v2` 公式和配置，只用于复现首轮模型，不静默改变旧实验语义；
- 模型结构、1-step Double DQN、30 FPS训练与30/120 FPS评估均未改变。

## 验证

- Conda `python-torch`运行99项全仓测试，全部通过；其中空间奖励、场景实验室和训练配置
  43项定向测试也单独通过；
- 本地RTX 4070以16环境、batch 8完成CUDA推理、V2.1奖励、更新、checkpoint往返、
  30/120 FPS评估和曲线快照预检；
- 本地8环境、batch 4完成24 transition正式trainer烟雾训练、两次更新与训练收尾；
- 本地128环境、batch 64、两轮成对吞吐烟雾门禁通过；短窗口噪声较大，只能证明未观察到
  超过8%的性能退化，RTX 5090正式规模仍需重新测量；
- 空场中央普通投放样例奖励为约 `-0.0062`，最佳边缘普通投放约为 `0`，不再由固定补偿
  获得无条件正奖励。
