## 自由空间质心修复

退化成单行或单列的自由空间区域可能包含多个完全相同的归一化坐标。旧
`sum(values) / len(values)` 会因累计和除法舍入，使均值比唯一坐标小一个 ULP，
从而违反“质心位于包围盒内”的严格 schema 不变量。

新版使用 `math.fsum` 降低累计误差，并把最终均值严格钳制在同一组样本的
`[min, max]` 内。有限样本均值在数学上必定位于这个闭区间，因此该钳制只消除
浮点尾差，不会改变区域成员、连通性、面积、边界水果或奖励语义。schema 仍保持
严格校验。

回归测试包含一个由 8 个一级水果构成的扁椭圆环。其封闭空腔恰好是一行 5 个
网格点，旧实现可稳定复现崩溃，新实现的 `centroid_y == min_y == max_y`。

## 三态复现门禁

原动作物理复现现在明确区分：

1. `strict_match`：现有完整比较门禁通过，允许继续运行替代分支并生成标签；
2. `numeric_jitter_drop`：离散语义完全一致，只有 Chipmunk 连续物理值越过严格
   容差；任务立即丢弃，不生成任何标签；
3. `semantic_divergence_drop`：得分、ID、等级、顺序、帧数、终止状态或其他离散
   语义发生分叉；任务立即丢弃并继续受独立 1% 门禁约束。

动作输入 `drop_x` 不属于物理积分抖动。`final_state_derived` 只有在同时出现真实
连续物理 mismatch 时才可随之归为 numeric；单独出现仍归为 semantic。
execution、comparison、runner 等未完成物理门禁的错误使用
`not_evaluated`，不能冒充任一物理三态。

普通反事实与局部 Shapley 结果跨进程携带五类独立最大误差：

- merge event position；
- fruit position；
- linear velocity；
- orientation；
- angular velocity。

协调器保留旧 `reproduction_passed/failed` 的兼容语义，同时新增 numeric、
semantic 独立计数和 numeric 五类误差最大值。最近反事实失败记录、checkpoint、
shutdown、训练 CSV 和训练目录 readiness 都能审计这些字段。只有
`reproduction_outcome == strict_match` 的结果可以进入因果 replay。

## Readiness 语义

每条物理链路独立计算：

```text
evaluated = strict + numeric + semantic
numeric_rate = numeric / evaluated
semantic_rate = semantic / evaluated
unknown = legacy_reproduction_failed - numeric - semantic
```

- `unknown` 必须为 0；
- numeric rate 只报告，首轮不设通过阈值；
- semantic 在至少 100 个已评估结果后必须不高于 1%；小样本非零只产生警告；
- 五类 numeric 最大误差必须存在、有限且非负；
- Shapley 仍必须至少有一个 strict completed 结果、样本写入和 optimizer 消费，
  且 subset、模型或 runner 等非门禁失败为 0；
- 普通反事实原有 executor、传输、结算、转换和 replay 基础设施门禁保持有效。

新 CSV/readiness schema 有意不把 v4 旧日志伪装成新版证据。修复后的 5k 必须从
update 0 和全新目录运行。
