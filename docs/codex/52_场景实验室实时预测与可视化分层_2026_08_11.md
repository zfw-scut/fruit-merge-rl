# 场景实验室实时预测与可视化分层

## 目标

把场景空间评估与辅助动作预测拆成两个可独立启用的诊断功能，并消除逐个水果、逐个动作
反复点击模型预测的操作成本。

## 实现事实

- 设置页按“基础画布”“辅助动作预测”“场景空间评估”“信息密度”分组；
- 场景空间评估默认关闭，只在明确勾选后显示空间势能、队列槽位和21列深度图；
- 实时辅助预测默认开启，在稳定场景或 q0～q3、场上水果变化后自动刷新；
- 一次模型前向仍返回全部21个动作，拖动 A0～A20 只切换缓存结果，不重复推理；
- 自动预测使用短防抖、稳定边界、场景键去重和单请求排队，避免实时物理状态流触发请求风暴；
- 实际验证结束后保持用户发起验证时所选动作，不跳转到模型首选或空间奖励最优动作；
- 预测、真实事实、误差线、法向量、新水果和 q0 最终后代均可独立显示。

## 性能边界

自动化只改变模型推理的触发方式，没有增加模型输出头，也没有按动作循环前向。动作滑杆的
交互成本仅为浏览器重绘。运动中的实时世界不会持续推理；只有再次稳定且场景内容不同才发起
请求。该功能不写入 Replay，不参与训练，也不改变 checkpoint。

## 验证

- `python -m unittest tests.test_scenario_lab`：15项通过；
- 使用24M辅助动作 checkpoint 在 CPU 上启动真实服务，页面载入后无需点击即出现动作预测；
- 从 A10 切换至 A16 后推理耗时显示保持不变，证明复用了同一批21动作结果；
- 暂停后切换 q0 水果等级，预测状态自动更新，浏览器控制台无错误；
- 场景空间评估默认隐藏，打开设置后可单独启用，不影响动作预测图层。

## 结论边界

本次验证的是交互、请求调度和可视化隔离，不构成辅助预测精度或策略效果的新评估结论。
