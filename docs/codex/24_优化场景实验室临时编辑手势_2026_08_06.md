# 优化场景实验室临时编辑手势

## 目标

让场景实验室保留持续实时物理，同时把常用编辑动作压缩成直接手势，不再要求用户先
暂停、切工具、修改、再恢复。

## 本次实现

- 运行态右键命中水果后，按稳定水果 ID 在下一物理帧边界删除；
- 左键按住场上水果时自动暂停并读取权威状态，拖动过程中直接修改位置；
- 松手时先载入编辑后的场景，再恢复实时物理，避免恢复命令越过场景同步；
- 快速点按、指针取消和 Esc 使用同一套收尾逻辑，取消时恢复拖动前状态；
- 运行态选中水果后可用 Delete 或选择卡片删除；
- 临时编辑期间锁定会冲突的工具、队列、撤销和运行切换控件，并显示
  “按住编辑 · 松手恢复”状态。

## 验证

- 参考物理世界覆盖按稳定 ID 删除与重复删除；
- 实时会话覆盖帧边界删除；
- 前端契约覆盖临时编辑、顺序同步和中文状态提示；
- 浏览器实测按住拖动后自动恢复、右键删除以及连续实时投放。

## 边界

永久暂停模式仍保留完整场景编辑能力；本次临时手势只优化运行态高频操作，不改变
Reward V2 评估流程，也不把前端状态作为物理权威来源。
