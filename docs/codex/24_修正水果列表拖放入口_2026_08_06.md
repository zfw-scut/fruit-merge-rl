# 修正水果列表拖放入口

## 修改原因

上一版把“按下拿起水果”错误理解成从画布空白处开始手势，只验证了画布内部拖动。
用户实际需要从左侧水果列表按下指定水果，保持按下移动到画布释放。

## 本次修改

- 左侧每个水果选项支持 Pointer Event 拖放，鼠标与触摸笔使用同一套事件路径。
- 水果尚未进入画布时显示跟随指针的悬浮预览；进入画布后改用真实场景比例预览。
- 只有在画布范围内松手才创建水果，画布外松手会取消，不污染场景历史。
- 松手后的自然落稳和真实轨迹播放继续复用现有接口。
- 保留画布空白处直接按住放置，作为快速构造场景的备用入口。

## 验证边界

前端契约检查同时覆盖水果列表拖放入口和悬浮预览元素；最终交互使用浏览器从左侧
水果选项跨区域拖入空白画布验证。实测樱桃在画布内松手后水果计数从0变为1，状态依次
进入真实轨迹计算和真实轨迹播放，并在播放初段保留释放位置的可见中间帧。
