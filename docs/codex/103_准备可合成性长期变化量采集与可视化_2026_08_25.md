# 准备可合成性长期变化量采集与可视化

## 修改原因

第一代可合成性画廊已通过主观初检，下一步需要知道该分数在真实策略长期投放中通常怎样
变化，尤其是正负尾部集中在哪些范围，之后才能讨论关键投放事件阈值。本轮服务器关闭，
因此只完成本地可实现的统计契约、采集工具、离线绘图和小规模验证，不写正式分布结论。

## 指标语义

- 游戏是二维圆形物理，水果占用量按`πr²`计算；
- 场景总体可合成值为所有活动水果`可合成分数×πr²`之和；
- 同局变化量为当前投放后总量减去上一投放后总量；
- 新局首个投放的差值标为无效，不跨终局重置做差；
- 总占用面积和面积加权平均分作为解释字段附带保存，不替代核心总量。

## 新增能力

- 新增场景总量和变化量的固定张量计算契约及分片表字段。
- 新增SAB-128 greedy长期rollout采集工具。CUDA环境自然终局后立即重置，保持批量槽位
  利用率；每条记录保留环境、episode、局内投放、得分、水果数、总体值和有效差值。
- 原始标量使用已有设备端累积与后台分片写入能力，避免逐环境Python对象和逐步大量回传。
- 新增独立分析工具，生成：变化量直方图与经验分布、正负尾部生存曲线、局内阶段分布、
  当前状态关系图和尾部分位数阈值参考表，同时输出JSON和CSV。
- 工具只展示候选分位数，不直接选择事件阈值，也不接入Policy、奖励或反事实逻辑。

## 本地验证

- Python编译通过；相关12项测试通过，1项显式CUDA一致性测试因本机限制跳过。
- 使用SAB-128在CPU上完成2环境×4投放端到端冒烟，得到8条记录，其中首投边界无效差值
  2条、同局有效差值6条；分片、manifest、summary、CSV和4张统计图片均成功生成。
- 冒烟数据量过小，只验证数据流和绘图，不可用于阈值判断。
