# 新增本地 UI 预览并修复 HUD 排版

## 修改原因

第一版暖色换肤虽然能够编译，但真机截图暴露出明显问题：libGDX 内置低分辨率字体
被高倍放大后模糊，标题、卡片与状态文字互相干涉，待投水果必然覆盖状态板，而且
`ShapeRenderer.arc()` 的 Line 模式会在圆角中额外画出半径线。仅靠构建和 Lint
无法发现这些表现层错误，因此需要先建立可重复的本地真实渲染验收入口。

## 主要修改

- 新增 LWJGL3 Windows 桌面模块，直接复用 Android 的
  `FruitMergeApplication`、Box2D 和 canonical 水果素材。
- 新增可交互预览和自动 framebuffer 截图脚本，支持按具体手机截图宽高验证
  `FitViewport` 与高倍率字体采样。
- 使用 OFL 1.1 授权的 Nunito 生成 64px BitmapFont；Android 与桌面加载同一
  `.fnt/.png`，不再放大 libGDX 内置 15px 字体。
- 用 `GlyphLayout` 按卡片内容矩形测量、居中和像素宽度截断所有文字。
- 将 HUD 收拢到 `y <= 140`，完整保留 `y=146..248` 给最大待投水果，删除会被水果
  覆盖的独立状态板。
- 删除所有后置圆角 Line outline，以填充外框与内框组合替代，消除圆角“方括号”
  和边框穿字。
- 棋盘去掉重复墙线，修正底部多延伸 20px 的视觉错误；弱化落点点列。
- 为下一颗队列增加槽位、标题叶片和 AI 状态小图标；水果贴图、尺寸、透明度、
  Box2D、AI 动作和移动模型均保持不变。

## 涉及文件

- `android/desktop/`：桌面预览与自动截图入口。
- `android/scripts/run-ui-preview.ps1`：一键交互预览/截图。
- `android/core/.../FruitMergeApplication.java`：字体、约束布局、绘制层级和 HUD。
- `assets/fonts/`、`tools/generate_mobile_ui_font.py`：共享字体、许可证与生成工具。
- `android/app/build.gradle`：同步共享字体到 APK assets。
- `docs/mobile/ANDROID_APP.md`：本地预览与字体维护说明。

## 备注

本地预览复用真实游戏渲染器，因此可作为后续 UI 修改的常规门禁；它不加载 Android
ONNX runtime，也不能验证刘海、安全区、触觉或手机 GPU 驱动，最终仍需安装 APK
做一次真机确认。
