# 修复场景实验室显示卡顿与工具切换

## 问题

- 后端物理以120 FPS推进，但前端只在收到60 Hz SSE状态包时重绘，调度抖动会直接变成画面卡顿。
- 运行态把三个工具按钮全部禁用，导致“放置”无法切换到“选择”。

## 修复

- 保持60 Hz状态发布，用浏览器显示帧循环在前后快照间插值位置和角度。
- 显示帧率跟随屏幕刷新率，不再把“120 FPS物理”标记误解为固定120 FPS画面。
- 运行态开放“放置/选择”切换，选择命中使用当前插值后的可见位置。
- “擦除”仍需先暂停，避免在物理线程运行时产生未定义的编辑语义。

## 旧分支边界

只保留旧 Android 成品“显示帧驱动更新、物理使用固定时步累积”的概念；
没有迁移其 Java、Box2D、渲染或输入实现。
