# 新增自定义场景实验室前端

## 修改原因

模型奖励和极端状态需要可重复验证，但当前回放器与模型观看器都只能展示已经计算完成的
轨迹，无法用鼠标直接构造场景。本次先固定交互和视觉方向，不提前耦合尚未设计完成的
场景加载、CUDA 状态复制或模型服务。

## 实现内容

- 新增 Windows 11 Fluent 方向的三栏场景实验室，画布为主要视觉焦点；
- 支持水果放置、拖动、右键删除、滚轮换级、撤销重做和 64 水果上限；
- 支持 q0～q3、21 动作投放探针、30/120 FPS、极端场景预设和 JSON 导入导出；
- 使用现有 11 级贴图和稳定规则半径，并提供越线、重叠等纯几何提示；
- 预留真实评估结果页和浏览器事件接口，未连接后端时不生成虚假物理或奖励；
- 新增无依赖 HTML 生成入口和前端结构测试。

## 旧分支审计

按旧经验索引只读查看了 `codex/work-1` 的 pygame 手动游戏、`playable_adapter.py` 和
`watch_dqn.py`。保留“鼠标目标清晰、稳定边界后再决策、表现层不反向依赖训练包”的
原则；没有迁入 pygame Board、Pymunk、旧 GraphBuilder、StateAnalyzer 或观看控制器。

## 验证

- 单元测试覆盖 11 级规则、页面关键结构、自包含贴图和后端未连接提示；
- 浏览器实际验证水果放置、拖动、右键删除、预设切换、队列修改和评估空状态；
- 1280×720 页面截图确认场景画布保持视觉中心，左右信息区无横向溢出；
- 浏览器控制台没有错误或警告。
