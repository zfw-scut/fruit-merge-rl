# 采用暖色果园 Android 外围 UI

## 修改原因

Android 首版的深色界面较为简陋，需要采用已选定的 A 版“暖色果园”方向提升背景、
信息卡、AI 提示和结束弹层的完成度，同时明确保留项目当前的水果贴图与显示行为。

## 主要修改

- 将背景改为奶油暖色渐变，并加入低透明暖光和程序绘制的叶片装饰。
- 将计分、最高分、下一颗、AI 开关和状态提示改为暖杏卡片与薄荷强调色。
- 将游戏板改为奶油底色和双层暖色边框；危险线改为珊瑚虚线，投放引导改为薄荷圆点。
- 将游戏结束弹层和 Android 启动/系统栏颜色同步到暖色主题。
- 保持水果加载、场内水果、待投水果和队列水果的纹理、尺寸、位置及透明度不变。
- 保持 Box2D、场景几何、AI 推理、21 动作和触控命中区不变。
- 保存三套 UI 选型稿，并在移动端文档中补充后续修改入口。

## 涉及文件

- `android/core/src/main/java/com/fruitmerge/ai/game/FruitMergeApplication.java`：
  暖色调色板、背景装饰、外围卡片、提示线、描边和结束弹层。
- `android/app/src/main/res/values/styles.xml`、`colors.xml`：
  启动背景与系统栏暖色适配。
