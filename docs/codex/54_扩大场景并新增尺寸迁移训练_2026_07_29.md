# 扩大场景并新增尺寸迁移训练

## 修改原因

后续实验需要把当前游戏场景的长、宽分别扩大约 40%，并利用既有模型快速适配新尺寸。
本项目不再维护旧场景尺寸兼容，因此本次直接切换项目默认几何规格，同时保留
weights-only 初始化入口，避免从零训练新模型。

## 主要修改

- 项目默认场景由 `400×800` 改为 `560×1120`，投放线同步由 `y=180` 调整为
  `y=252`；水果尺寸和物理参数不随场景缩放。
- 离散投放动作由 15 个增加到 21 个，保持与原场景接近的横向动作密度；完整状态归因
  动作掩码和 schema 同步升级。
- 游戏、训练环境、反事实归因、局部 Shapley、模型观看和物理模式对比统一使用显式
  场景几何，避免 snapshot 重建时退回错误尺寸。
- 训练入口新增 `--init-checkpoint`。该入口只继承旧 checkpoint 的在线模型权重，
  并用它初始化新的 online/target 网络；优化器、replay、随机数状态、训练步数和
  调度状态全部重新开始。
- 新增 `train_dqn_size_transfer_560x1120_50k.toml`，用于在用户确认视觉尺寸后进行
  50K 尺寸迁移训练。

## 设计边界与兼容性

- 不保持旧 `400×800`、15 动作训练流程的继续训练兼容性；新默认规格就是当前项目
  唯一维护目标。
- 旧 checkpoint 的网络参数形状仍可通过 weights-only 方式迁移，但不能把旧
  checkpoint 当作新规格训练的完整 resume 状态。
- 旧 replay 中的动作索引、15 位归因掩码和旧场景状态分布与 21 动作新场景不兼容，
  因此不复用旧 replay。
- 旧 optimizer 动量、RNG、训练计数器和 epsilon/调度进度均不继承，避免把旧场景的
  优化轨迹错误延续到新任务。

## 涉及文件

- `src/daxigua/config.py`、`src/daxigua/core/board.py`、`src/daxigua/app.py`：
  切换默认场景尺寸，并支持显式传入场景几何。
- `src/daxigua_rl/env.py`、`src/daxigua_rl/playable_adapter.py`：
  统一训练环境几何和 21 个投放候选位置。
- `src/daxigua_rl/attribution/schema.py`、
  `src/daxigua_rl/attribution/counterfactual_runner.py`、
  `src/daxigua_rl/attribution/local_shapley_runner.py`：升级归因动作掩码并在
  snapshot 重建时保留几何信息。
- `src/daxigua_rl/scripts/train_dqn.py`、
  `src/daxigua_rl/training/checkpointing.py`：新增 weights-only 初始化流程及初始化
  来源记录。
- `src/daxigua_rl/scripts/watch_dqn.py`、
  `src/daxigua_rl/scripts/compare_physics_modes.py`：让观看和对比入口使用当前或显式
  指定的场景几何。
- `configs/train_dqn_size_transfer_560x1120_50k.toml`：新增尺寸迁移训练配置。
- `tests/test_game_geometry.py`、`tests/test_size_transfer.py` 及相关测试：
  覆盖新默认尺寸、21 动作、snapshot 几何和权重迁移边界。

## 使用方式

本地查看新场景：

```powershell
python Main.py
```

也可以显式指定同一规格：

```powershell
python Main.py --board-width 560 --board-height 1120 --spawn-y 252
```

用户确认视觉尺寸后，用旧模型权重启动新的迁移训练：

```powershell
$env:PYTHONPATH = "src"
python -m daxigua_rl.scripts.train_dqn `
  --config configs/train_dqn_size_transfer_560x1120_50k.toml `
  --init-checkpoint runs/<旧训练目录>/checkpoints/<checkpoint>.pt
```

## 验证方式

- 完整测试共运行 392 项，结果为 `OK (skipped=1)`；最终以主代理完成提交前的复核结果
  为准。
- 新增测试验证默认 `560×1120`、`spawn_y=252` 和 21 个投放候选位置。
- 新增测试验证旧 checkpoint 只迁移网络权重、target 从迁移后的 online 初始化，
  以及架构不一致时拒绝迁移。

## 备注

- 本次尚未启动云端尺寸迁移训练。
- 需先由用户查看本地新场景并确认尺寸合适，再把代码同步到云服务器并启动训练。
- 场景面积约增加 96%，即使继承旧模型权重，也应把尺寸迁移视为新的训练任务，并重点
  观察探索效率、局面高度分布和 21 动作下的归因质量。
