# 实现历史归档

本目录记录每次修改发生时的事实，不是当前接口说明。

- 先从 `../STAGE_INDEX.md` 选择当前或最近相关阶段，再按标题/关键词只读一份记录。
- 禁止从 `01` 开始顺序阅读，也不要因编号较早就把旧默认值带入当前实现。
- 记录之间冲突时使用较新阶段；与当前代码、配置、测试或当前操作文档冲突时，以后者为准。
- `09` 已被 `53` 覆盖；早期训练/场景独立页面已被 `61` 覆盖；Pymunk 场景后端已被 `66` 覆盖。
- 历史训练和评估仍可作为带物理身份的证据，但不能自动成为当前方案依据。

新增记录写入 `RULES.md` 规定的结构。只有项目目标或核心契约发生阶段变化时才更新阶段索引。
