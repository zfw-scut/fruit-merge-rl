# 建立训练事实与派生监督扩展框架

## 修改原因

后续计划依次研究辅助动作效果学习、反事实行为段归因、最优性能差距课程、分层强化学习
和 BMCTS。若每项能力分别侵入现有训练主循环，会重复保存状态并重新引入旧分支在线分析、
复杂状态机和 IPC 成本。因此先建立不绑定具体优化算法的事实与派生监督框架。

## 新增与保留

- 保留当前 CUDA simulator、GNN-DQN、GPU Replay、1-step Double DQN 和 reward 语义；
- 新增 `DecisionDataConfig`，默认关闭；
- Replay 可选启用带 generation 的只读状态引用，覆盖后可在设备端识别失效；默认关闭时
  不分配 generation Tensor 或增加对应写入；
- 模拟器新增只读 `BatchDecisionSidecar`，补充 ID、RNG、危险计数等精确重放字段；
- 新增动作选择、固定容量候选、事实批次和通用派生监督契约；
- 新增两阶段 selector 接口，但不定义关键决策条件；
- 新增可选 GPU 有界事实缓冲；
- 新增有界异步分片归档、原子提交和 manifest；
- `BaselineTrainer` 以依赖注入方式接入 selector/sink，复用现成 Q 值并在 reset 前发布事实；
- 事实与派生监督分离，未来任务只能追加结果，不能覆盖真实 transition。

## 当前未实现

- 辅助动作预测目标与 loss；
- 行为段划分和反事实状态恢复；
- 反事实调度、因果 replay 与归因算法；
- 最优解上下界和课程调度；
- 高层规划器、BMCTS 和多 GPU worker。

这些能力只通过现有扩展接口预留，不作为当前训练运行依赖。
