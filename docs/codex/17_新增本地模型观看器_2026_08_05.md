# 新增本地模型观看器

## 修改原因

云端训练采用“高负载训练一代、关闭服务器、本地分析迭代”的流程。仅有批量评估数值和
训练面板不足以观察模型为何选择某个落点，因此需要一个能直接加载下载 checkpoint 的
本地可视化入口。

## 实现内容

- 新增当前 checkpoint 的严格模型重建和在线网络权重加载；
- 默认使用 120 FPS 高保真物理执行 greedy 模型，也可显式选择 30 FPS；
- 每次投放保存逐帧真实物理、q0～q3、21 个 Q 值、选定动作、落点和危险进度；
- 扩展已有自包含浏览器播放器，增加模型决策卡片和 Q 值柱图；
- 新增 `tools/watch_gnn_dqn.py`，支持单局、多局目录、追踪归档和生成后打开页面；
- 保持普通随机物理回放兼容，缺少模型元数据时决策卡片自动隐藏。

## 旧分支审计

只读审计了 `codex/work-1` 的 `watch_dqn.py`、`playable_adapter.py` 和对应测试。复用其
“按 checkpoint 重建、稳定后决策、控制层与训练解耦”的原则；没有迁入 pygame Board、
旧动态 GraphBuilder、StateAnalyzer、旧模型或 Android/ONNX 运行时。

## 验证

- checkpoint round-trip 后可在 CPU 严格重建相同当前模型；
- 回放扩展元数据经过 gzip HTML 编解码后完整保留 21 个 Q 值；
- 本机 CUDA smoke checkpoint 在 120 FPS 下完成两次 greedy 投放并生成 HTML/PT.GZ；
- 浏览器实际检查了首个和第二个投放，动作、q0～q3、落点和 Q 值柱图随投放同步更新；
- smoke 权重训练量极小，本次结果只证明观看链路，不证明策略质量。
