# 接入场景实验室模型推理与持续决策

## 修改原因

场景实验室已经能手工构造状态并诊断 Reward V2，但只能单独查看空间奖励，无法直接
观察当前 checkpoint 对同一状态的动作偏好，也不能让模型从手工场景继续真实游玩。

## 新增与保留边界

- 新增 `/api/model/evaluate`，对手工场景只读返回 A0～A20 的 Q 值和 greedy 动作；
- 新增 `/api/model/control`，启动或停止当前 checkpoint 的持续决策；
- 持续控制要求约0.125秒连续稳定，拓扑变化、运动和暂停会清空稳定累计；
- 模型动作进入持久化 Pymunk 世界的原生 `drop(action)`，自然推进 q0～q3；
- 启动持续模式时保留当前手工场景，停止时也不重置；终局、错误或1000次投放上限会自动停止；
- 手工载入、删除、清空或投放会先停止模型控制，避免并发写入物理世界；
- 保留单次模型倾向与21动作 Reward V2 的同快照对照，不把模型控制接入训练热路径。

只保留旧分支观看器“连续稳定窗口和拓扑变化后重新累计”的原则，没有迁入旧 pygame
控制器、动态构图、`StateAnalyzer` 或旧 checkpoint 适配层。
