# 实现轻量合成步距预测器训练链路

## 原因

Merge Potential 20,000局统计确认`T_merge`随等级存在明显不同的时间尺度和自然终局未合成
概率。下一阶段先用`SAB-128`作为行为teacher重新采集完整场景，独立训练一个逐水果轻量
预测器；本阶段不提前接入或训练RL融合模型。

## 实现

- 新增`merge_distance.py`：复用当前SAB物理水果图语义的浅层GNN，对每个活动槽位输出
  对数时间区间、`1024+`长尾合成和自然终局未合成的离散生存分布；
- 新增`merge_distance_data.py`：按完整稳定场景保存64槽Tensor状态，使用
  `episode_id + fruit_id`关联未来首次合成，并按episode划分训练/验证/测试；
- 新增`train_merge_distance_predictor.py`：提供`collect / label / train / evaluate`四个阶段，
  默认核对`SAB-128 final.pt`哈希、关闭自由下落加速并保持真实无投放上限；
- 训练阶段支持分片流式读取、生命周期权重、等级×结果平衡、BF16、`torch.compile`、
  验证NLL早停和最终测试指标；
- checkpoint保存预测器结构、几何、teacher数据身份、指标和精确权重，后续可独立冻结加载。

## 保留边界

- 不使用旧Merge Potential分片作为模型训练数据；旧统计只提供设计证据；
- 不实现RL融合、在线联合loss、奖励修改或Replay扩展；
- 不登记正式模型短称，等待云端训练完成并归档预测效果后再命名；
- 不在本地运行大规模采集或训练。

## 验证

- 逐水果类别映射、长尾和自然终局未合成语义通过；
- 轻量模型在CPU小场景完成前向、离散生存loss和反向传播；
- 场景抽样器、固定槽位保存、未来事件关联、重复生命周期权重通过；
- 合成小分片完成一次`train → validation → test → final.pt`闭环并严格加载；
- 新增测试及相关RL、辅助旁路回归共54项通过；
- 正式云端吞吐、存储规模、预测精度和校准尚未执行，不能提前写成模型效果结论。
