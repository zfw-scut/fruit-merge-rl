# 归档Reward V2.1首轮训练

## 记录原因

Reward V2.1完成首轮RTX 5090正式训练，需要在关闭云服务器前迁回全部可复核产物，并把
奖励校正是否转化为真实策略改善写入统一模型评估知识库，供下一轮奖励设计直接使用。

## 训练身份

- 提交：`4c8ce1815803688cac9a99eaa738c83b729d0fb5`；
- 运行：`cloud_rtx5090_reward_v2_1_4c8ce18_seed20260805_16m_90m`；
- 设备：RTX 5090，1792环境、batch 1792、BF16、编译模型；
- 奖励：`spatial_v2_1`；训练物理30 FPS，最终评估30/120 FPS各4096局；
- 目标 / 实际：16,000,000 / 13,143,040 transition，7188次更新、55,462局；
- 主训练约60分钟，包含双帧率最终评估与离线分析导出的总运行约78分钟。

## 云端性能门禁

- 相同配置成对测得`score_v1`中位吞吐8601.26 env steps/s，`spatial_v2_1`为
  8527.71 env steps/s，净开销0.855%，通过5%警告和8%阻断门限；
- 正式训练1M transition后窗口吞吐中位数4536.88 env steps/s；
- GPU利用率中位数99%，显存25,778MB / 32,607MB，GPU负载达标。

## 迁移结果

- 正式run、预检和成对性能报告已合并为214MB归档并迁回本地；
- 归档SHA-256：`6b0ef551e486e2280450bc017e0988f9839e0a744d50a1d2f92418f43112eb6e`；
- 解压后正式run约954MB，包含全部checkpoint、双帧率评估、曲线、资源日志、
  512局30 FPS决策轨迹和131,072条均匀Replay样本；
- 内部清单15项中14项逐文件匹配。`artifact_manifest.json`生成后，面板追加了最后一条
  `training_finished`事件，使`monitoring.jsonl`比清单多272字节；外层归档哈希与远端一致，
  不是网络中断或文件丢失。

## 效果结论

- 30 FPS局均分2555.24，120 FPS局均分2341.71；相对Reward V2分别提高1.17%和1.39%，
  但相对分数基线仍低22.10%和23.31%；
- 近似无合成奖励均值由+0.01098降至-0.00201，正奖励率由97.43%降至37.22%，
  固定补偿造成的奖励偏正已修复；
- 合成与无合成奖励均值间隔没有扩大，约26.36%的近似合成样本为负；
- 30 FPS最外侧动作占比从Reward V2的30.72%升至36.91%，最小水果的两侧动作占52.00%；
- V2.1只是给所有实际动作增加一个状态相关共同基线，没有修复21列空间指标本身的动作排序，
  因此真实策略只获得小幅改善。
