# 接入合成步距预测训练遥测

## 原因

轻量合成步距预测器将在云端重新生成场景数据并独立训练，需要在既有Xigua Atlas中直接
观察采集、标签和训练进度，避免另行维护临时面板或只依赖终端日志。

## 实现

- 新增预测工作流只读状态扫描，只读取规范目录中的`manifest.json`、
  `dataset_manifest.json`和小型`metrics.jsonl`；
- 场景采集沿用按对局和投放吞吐的进度，离线标签按场景分片原子刷新；
- 训练每10秒刷新心跳，每个epoch记录训练loss、验证NLL、生命周期加权NLL、精确与相邻
  区间准确率，并区分训练、验证、最终评估和完成状态；
- 既有云端8765遥测API和本地门户代理增加`merge_distance`字段，远端不可用时仍可发现
  本地任务；
- 实时训练页新增专用卡片和epoch曲线，不把监督学习指标伪装成RL投放、得分或DQN字段。

## 边界

- 门户保持只读，不读取场景张量、不控制训练进程；
- 不改变预测器标签、模型结构、loss或RL融合边界；
- 本阶段只用合成小数据和模拟清单验证，不执行正式云端训练。

## 验证

- 门户与预测器后端测试通过；
- 前端ESLint和生产构建通过；
- 在隔离端口用模拟训练清单实际渲染，确认进度、指标、曲线及既有统计卡片可同时显示。
