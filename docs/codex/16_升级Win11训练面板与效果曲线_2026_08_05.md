# 升级 Win11 训练面板与效果曲线

## 目标

第一版正式训练需要在云端高负载运行期间快速确认训练进度、资源是否吃满以及策略效果
是否持续改善。原始面板只提供即时数字，且演示版的经典 Win32 外观不符合最终界面方向。
本次将面板统一为 Windows 11 Fluent 风格，并补齐训练效果历史曲线。

## 已完成设计

- 面板继续由独立低优先级进程运行，只读展示训练状态，不进入训练热路径；
- 中文为主、英文术语为辅，采用轻透背景、圆角卡片、柔和阴影和现代强调色；
- 按整数、速率、百分比、分数、时长和容量分别格式化数字，缺失值统一显示 `—`；
- 展示统计窗口局均分、统计窗口最高分、滚动局均分与训练历史最高分；
- 在分数图中保留 30 FPS 和 120 FPS 评估序列，直接观察物理帧率差异；
- 独立展示 Huber 损失/TD 误差和投放/学习吞吐曲线；
- 将 21 个动作改为可比较的分布柱图，事件名称使用中文解释。

统计窗口分数只在低频详细指标发布时写入历史，不增加逐 transition 的 CPU 同步、绘图
或磁盘操作。页面历史保存在监控进程的有界内存中，面板断开不会影响训练。

## 旧分支边界

本次按索引只读审计了 `codex/work-1` 的旧监控页面。只保留“训练热路径与监控解耦、
高频轻指标和低频重指标分层”的通用经验；HTML、样式、运行服务和旧训练接口均未迁入，
当前面板是 accelerated-v1 的独立实现。

## 验证要求

- 单元测试确认分数窗口指标进入历史序列；
- 页面必须存在中文训练效果曲线和 Win11 Fluent 风格标记；
- 页面不得重新出现经典 Win32 的“文件(F)”菜单；
- 本机演示数据只用于检查排版和曲线，不代表真实训练成绩。
