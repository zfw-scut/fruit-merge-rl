# 实现HTML模型知识与工具门户

## 1. 需求

项目Markdown和模型报告已经形成较大知识库，但命令行检索、文件跳转和脚本参数输入使
日常阅读与操作割裂。本次单独建立`codex/docs-visual-platform`分支，实现一个强调阅读
体验、数据可视化和流畅交互的本地HTML门户，不改动训练热路径或模型算法。

## 2. 实现事实

- 新增`portal/` React/Vinext前端，使用ECharts绘制模型柱状图与训练规模散点图，使用
  Framer Motion完成视图、卡片、弹层和状态过渡；
- 新增`daxigua.portal`回环API，实时扫描Markdown、提供轻量revision检测、代理现有训练
  面板状态并管理白名单工具进程；
- 新增统一入口`tools/open_project_portal.py`，启动本地API和前端并打开浏览器；
- 全文搜索覆盖文档标题、路径和正文，Markdown支持表格、代码块、图片与仓库内链接；
- 工具中心登记场景实验室、历史训练面板、模型观看器和CUDA训练门禁，参数用选择器、
  分段按钮、滑杆和数值框表达；
- 实时训练页复用原有8765面板，不向actor或learner热路径增加采集；
- 页面明确标注旧继承动量模型与当前零初速度物理的身份边界。

## 3. 安全边界

门户不是通用终端。API只绑定回环地址，命令以固定参数数组和`shell=False`启动；路径必须
位于项目允许目录，枚举和数值范围由后端再次验证。没有加入服务器密码存储，也没有提供
无需确认的正式长训按钮。

## 4. 验证

完成以下验证：

- `npm run lint`通过；
- `npm run build`通过；
- `python -m unittest tests.test_portal_service -v`四项通过；
- 浏览器检查总览、模型图谱、文档检索、工具参数弹层和8765实时面板，无控制台错误；
- 检查文档保存后的轻量revision刷新、桌面/移动断点和`prefers-reduced-motion`降级样式。

## 5. 证据边界

主页图表只汇总已经进入正式模型评估知识库的代表模型。训练时长是近似投入视图，不伪装
成精确计费事实；图表交互始终允许返回原始报告。门户完成仅表示阅读和工具入口可用，不能
据此推导任何模型策略效果提升。
