# 实现第一版 GNN-DQN 训练系统

## 修改原因

新模型后续升级需要一个结构合理、速度可测且能稳定复现的第一版基线。首轮 RTX 5090
租用还承担服务器性能上限标定任务，因此本次同时实现模型、正式训练主链、低开销监控、
独立评估、性能扫描和分析产物导出，避免到服务器上临时拼接关键路径。

旧分支 `codex/work-1` 只用于只读经验审计。本次没有迁移旧模型、状态分析、因果归因、
反事实或多进程 Actor RPC，也没有建立任何旧分支运行依赖。

## 新增和修改

- 批量观察新增 `danger_progress` 与当前越过危险线标志；
- 新增定长混合局部物理 GNN、q0～q3 队列消息、全局聚合和 21 个单向动作探针；
- 新增 1-step Dueling Double DQN、均匀 GPU 环形 Replay、BF16/fused Adam 可选路径和
  可跨 eager/`torch.compile` 恢复的 checkpoint；
- 正式采集、Replay、TD target 和 loss 固定使用 30 FPS，120 FPS 只由隔离 evaluator
  读取同一 checkpoint，不向 Replay 写入数据；
- 预热环境使用真实物理分散到不同局面阶段，再按初期、发展、拥挤和危险阶段填充配额；
- 新增云端预检、独立子进程性能扫描、正式 Replay 显存投影、自动配置选择和训练中动态
  活跃环境扩容，并为最终选中配置输出短 Chrome Trace；
- 新增非阻塞独立 Web 面板与资源采样旁路，CPU 不承担 rollout 或构图热路径；
- 新增原子 checkpoint、30/120 FPS 评估、Replay transition 抽样、完整 30 FPS 决策
  边界轨迹和 SHA-256 产物清单；
- `torch.compile` 是可选压测候选；候选编译失败时会被记录并排除，不影响 eager 训练。

第一版没有加入战略 Pair Encoder、等级/区域聚合、高层计划器、FiLM、动作效果辅助任务
或 BMCTS。这些模块继续作为相对于本基线的独立升级和消融项。

## 主要文件

- `src/daxigua/rl/`：状态适配、模型、Replay、learner、trainer、评估、监控、扩容、
  checkpoint 和性能标定；
- `src/daxigua/simulator/types.py`、`src/daxigua/simulator/vector.py`：危险状态观察契约；
- `configs/gnn_dqn_baseline.toml`：冻结的第一版正式训练配置；
- `tools/preflight_training.py`：云端正式运行前正确性门禁；
- `tools/benchmark_training_pipeline.py`：环境数、batch、精度和编译候选扫描；
- `tools/run_autotuned_training.py`、`tools/train_gnn_dqn.py`：自动调优和直接训练入口；
- `scripts/run_cloud_training.sh`：预检、标定、正式训练的一次性 Linux 入口；
- `requirements-training.txt`：训练面板和资源采样附加依赖；
- `tests/test_rl_baseline.py`：模型、Replay、learner、评估轨迹、扩容和 checkpoint 契约。

## 本机验证

- 完整测试：`60` 项通过；
- RTX 4070 Laptop CUDA 预检：模型输出为 `[8, 21]`，一次 Double DQN 更新 loss 有限，
  Target 同步和 checkpoint round-trip 通过；
- 30 FPS 与 120 FPS 各完成 2 局隔离评估，报告明确记录
  `accurate_replay_writes = 0`；
- CUDA 正式 smoke：完成 24 个训练 transition、2 次 optimizer update、30/120 FPS
  最终评估、dashboard 日志、best/latest/final checkpoint、transition 抽样、完整决策
  轨迹和产物清单；
- 性能扫描工具完成本机 CPU 子进程选择验证；RTX 4070 的小型 CUDA 候选也完成物理、
  Actor、Learner 和 UTD=1 端到端测量；
- 本机 Windows 的 `torch.compile` 候选因没有可用 Triton 被正确判定为失败。默认 eager
  路径不受影响，Linux 云端将重新实测后再决定是否启用。

本机结果只证明主链完整，不作为 RTX 5090 正式环境数、batch 或吞吐结论。云端必须重新
执行预检和性能标定，再冻结首轮配置。
