# 合成水果初速度归零

## 规则

两个同级水果合成后，若会生成下一级水果，则新水果：

- 仍在两个来源水果圆心的算术中点创建；
- 创建瞬间线速度固定为`(0, 0)`；
- 创建瞬间角速度固定为`0`；
- 显示角度仍重置为`0`。

两个11级水果相消时不产生目标水果。计分、合成等级、碰撞半径、质量、事件位置、
水果ID与q0谱系语义均未改变。

这里的“初始为零”只约束创建瞬间。新水果在后续物理帧中仍会受重力、碰撞、摩擦和阻尼
影响，因而到下一个决策边界时速度不一定为零。

## 实现

- Tensor CPU合成路径不再计算来源线动量和角动量，直接向目标槽位写入零速度；
- CUDA融合Kernel删除动量继承计算，创建目标水果时写入零线速度和零角速度；
- Pymunk参考环境在创建合成水果后显式写入`(0, 0)`和`0`；
- 三条路径继续共享相同的中点、计分、西瓜相消和事件契约。

## 历史边界

当前已归档模型、训练数据、回放和模型评估均产生于旧“动量继承”规则。它们仍是有效历史
证据，但不能与新规则下的训练结果视为同一物理分布的严格对照。尤其是辅助动作模型中的
新水果后续轨迹和q0最终速度预测仍按旧规则学习；加载旧checkpoint只表示结构兼容，不表示
预测已适配新物理。

旧分支`codex/work-1`的Pymunk实现原本就让合成水果使用默认零速度。本次没有迁移旧代码，
只在当前Tensor、CUDA与参考模拟器接口中重新实现已确认规则。

## 验证

- Tensor CPU直接合成测试以非零来源速度和角速度确认目标水果创建后两者严格为零；
- Pymunk参考合成测试确认同一语义；
- CUDA测试契约改为确认单物理帧合成结果的线速度、角速度严格为零；
- 确定性配对、连锁合成、西瓜相消和合成事件语义继续执行回归测试。
