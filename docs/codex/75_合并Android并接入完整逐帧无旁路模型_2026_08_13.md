# 合并 Android 并接入完整逐帧无旁路模型

## 修改原因

Android 游戏此前保存在独立分支，需要以当前 `main` 的训练与物理契约为准合并回来，并将
完整逐帧120 FPS训练中表现更好的无旁路模型接入应用。

## 合并与接入

- 合并 `codex/android-ai-demo-physics-fix`，冲突以当前 `main` 为准；
- Android 模型更新为 `SAB-FF120` 的 `final.pt`，checkpoint SHA-256 为
  `a09d0683edc2e061d93cbc7f8ad8a64ba50e33af7f38cd8bf40d3a78f2e6d211`；
- 导出 `sab_ff120.onnx`，SHA-256 为
  `b10b8fbf853e07397e9a1774b1b7fd394e42502d41ff7700cfb76cbf5a4a4475`；
- 构建门禁同时校验正式模型ID、`final`角色、完整逐帧物理身份、无旁路标志和两级哈希；
- 删除 Android 分支遗留的逐水果运动学休眠，不再累计 `quietFrames`，也不再人为清零
  线速度或角速度；保留正常阻尼、碰撞和决策稳定边界。
