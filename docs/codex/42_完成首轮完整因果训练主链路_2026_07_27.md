# 完成首轮完整因果训练主链路

## 修改原因

第一次 500k 训练计划直接启用完整状态归因，且项目只安排少量大规模训练机会。此前
Reward V2、StateAnalyzer 和 AttributionTracker 已能在真实轨迹上识别任务价值与历史
贡献，但训练侧仍缺少因果回放、直接 Q 约束、可恢复物理快照、稀疏反事实、局部
Shapley 和可靠长训恢复。本轮把这些部分一次接入正式训练主链，并增加长训前门禁。

## 主要修改

- 新增独立 `CausalReplayBuffer`。规则样本按原因和正负方向分层，物理反事实可覆盖
  同一动作对的较弱规则结论，并保留规则/经验一致性统计和图张量共享。
- DQN target 改为 Double DQN，collector 按 worker 连续轨迹生成 3-step return；
  terminal 截断回报，truncated 继续 bootstrap。训练同时计算 TD、规则排序和物理
  return 差监督，并对非有限 Q、target、loss 和梯度 fail-fast。
- 新增可完整恢复 Pymunk 隐藏物理状态的 `EngineSnapshot`，快照包含队列、RNG、
  刚体/shape/space 参数和碰撞 arbiter；规范快照支持原动作逐步精确复现。
- worker 只保留 32 个稳定边界的有界快照环，并把已确认、高价值事件构造成严格
  proposal。主进程使用独立 coordinator、worker、队列、熔断和共享 token ledger
  执行 10 步稀疏物理反事实，低价值或超预算任务不阻塞 rollout。
- 新增极稀疏局部 Shapley。只对 2～4 个高价值协同候选执行子集物理重演、paired
  permutation 和 1% 效率门；grand coalition 不能复现时不会产生伪标签。
- 第一次长训默认完整启用 Reward V2、Double DQN、3-step、规则因果监督、
  `lambda_cf`、6% 软反事实预算、10% 共享硬上限和 0.05% 局部 Shapley 配额。
- 训练 CSV 增加 proposal、反事实调度/复现/token、Shapley、因果 replay 分层和各
  阶段性能指标；正常退出会等待已获批物理任务，异常会原子写入完整现场诊断。
- checkpoint 改为版本化原子写入，保存模型、target、optimizer、计数器、RNG、
  因果 replay 和 TD hot replay。恢复时严格校验配置指纹、同 run 目录和 CUDA RNG
  设备数，并收口超前 CSV 行；worker 从新的 episode 边界继续。
- 新增 5k 冒烟、10k 校准和 500k 正式配置，以及一次性 preflight，验证正式配置、
  CUDA、完整因果 optimizer step、局部 Shapley、32 次快照复现、磁盘和 CPU 余量。
- 新增首轮运行手册和 readiness 记录，把安装、监控、停止阈值、恢复语义和阶段门禁
  固定下来。

## 验证方式

在 `python-torch` 环境完成：

```text
PYTHONPATH=src:tests python -m unittest discover -s tests -p "test_*.py" -v
python -m compileall -q src tools tests
python tools/preflight_training.py \
  --config configs/train_dqn_causal_500k.toml \
  --output runs/preflight/first_500k_pre_smoke.json \
  --snapshot-audits 32 \
  --min-free-gb 80
```

结果：

- 全量 245 项测试通过。
- preflight `ready=true`，无 required failure 和 warning。
- CUDA 正式 batch 64 的完整因果 optimizer step 通过，物理反事实生成 2 个样本。
- 局部 Shapley 完成 2 个候选、4 个 subset、8 次 paired permutation，生成 2 个
  样本，效率残差为 0。
- EngineSnapshot 原动作复现 32/32，最大位置误差为 0。
- 证据 commit 为 `7d7676f359ca6f8f7f3a5ced7fb5da7361b5a473`，preflight 时工作树干净。

上述测试与 preflight 是 commit `7d7676f` 的历史里程碑，不代表后续修改后的当前
源码已经通过最终门禁。

## 备注

- checkpoint 只能从可信来源加载。正式 hybrid TD replay 只恢复最近 hot layer，
  因果 replay 精确恢复；worker 物理轨迹和在途物理任务从新 episode 边界重建。
- 反事实和 Shapley 均以原动作物理复现为硬门，失败任务只进入诊断，不进入训练。
- 500k 正式训练尚未启动。5k 和 10k（必要时从 update 0 另起的独立 25k）门禁
  通过、云端重新 preflight 且源码身份冻结之前，不应把静态 `ready=true` 解释为
  长训启动许可。若从 10k checkpoint 连续延长到 25k，冻结的 epsilon horizon
  不变，必须明确标记为连续延长，不能替代独立 25k 的可比校准证据。
