# 新增 Windows 桌面一键训练面板

## 目标

把本地访问云端训练面板的认证、SSH 回环隧道和浏览器启动整合为一个可双击的 Windows
桌面快捷应用，同时避免把明文密码写入仓库、脚本、快捷方式、进程命令行或日志。

## 实现

- 新增 Windows PowerShell 安装器，把运行文件安装到当前用户
  `%LOCALAPPDATA%\FruitMergeRL\TrainingDashboard`，并在 Windows 返回的当前桌面
  创建 `合成大西瓜训练面板.lnk`。
- 安装时只通过 `Read-Host -AsSecureString` 录入一次密码，立即用当前用户范围的
  Windows DPAPI 加密为 `credential.bin`；文件 ACL 只允许当前用户和 SYSTEM。
- ASKPASS 使用安装时编译的真实 Windows PE 小程序，不依赖 `.ps1` 或 `.cmd` 文件
  关联。辅助程序只处理 password/密码提示，不记录错误或凭据。
- 启动器用无窗口 OpenSSH 进程建立
  `127.0.0.1:<local>:127.0.0.1:8765` 转发，并保留主机指纹校验。
- 启动前核对 `/api/health` 的 schema 和状态字段；不把 stale 数据误判为非本项目
  面板。隧道状态同时绑定 SSH 主机、用户、SSH 端口和远端面板端口，只复用同一目标
  的自有健康隧道；配置变化时安全结束自有旧隧道后重建。
- named mutex 防止重复双击竞态；8765 被其他程序占用时尝试 18765、28765，不结束
  未知进程。
- SSH 提前退出或面板启动超时时，只结束本次启动持有的 SSH `Process` 对象。持久化
  PID 同时记录进程启动时刻，卸载时不会按进程名模糊停止。
- 桌面快捷方式使用 `wscript.exe` 和 VBS 薄包装层，避免弹出 PowerShell 控制台。
- 新增简约深色图标，以合成水果和上升训练曲线表达项目与监控用途，并打包 16～256
  像素 ICO 帧。

## 本机验收

- Windows PowerShell 5.1 能解析两个 UTF-8 BOM PowerShell 脚本。
- ASKPASS C# 源码能由 Windows PowerShell 5.1 编译为控制台 PE。
- ASKPASS 直接向标准输出写入 DPAPI 解密后的 UTF-8 字节，非 ASCII 密码不会被本地
  Windows 代码页重新编码。
- DPAPI blob 可由当前用户解密，明文长度正确；凭据 ACL 只有当前用户和 SYSTEM。
- 安装后的 `.lnk` 目标、参数、工作目录、图标和描述均指向本地应用目录。
- 安装后的启动器已真实连接当前云服务器，`/api/health` 返回 schema 1，面板状态为
  completed。
- 连续运行两次启动器保持同一 SSH PID，匹配隧道进程数始终为 1。
- 实际启动桌面 `.lnk` 后观察到 VBS/PowerShell 包装链路执行、默认浏览器打开、面板
  继续可达，SSH PID 未变化。
- 临时关闭自有隧道后，对安装目录、SSH 日志、源码和快捷方式共 14 个文件完成精确
  明文凭据字节扫描，命中数为 0；恢复后的 SSH 命令行也不含实际凭据。

## 安全边界

DPAPI 防止凭据被其他 Windows 用户或脱机复制后直接解密，但同一 Windows 用户下的
恶意进程仍然处于相同信任边界。该入口适合当前数天内使用的短期云服务器；服务器
释放后应执行安装器 `-Uninstall` 或重新录入后续服务器凭据。
