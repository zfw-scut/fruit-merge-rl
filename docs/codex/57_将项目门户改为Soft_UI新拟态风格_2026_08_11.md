# 将项目门户改为 Soft UI 新拟态风格

## 1. 视觉判断

参考界面属于浅色`Neumorphism / Soft UI`，并融合现代SaaS Dashboard的信息布局。其核心
特征是冷灰同色表面、左上高光与右下柔影构成的轻浮雕层级、克制的圆角和单一高饱和蓝色
强调，而不是普通白底后台或玻璃拟态。

## 2. 本次调整

- 保留模型轨道、状态脉冲、页面过渡和图表更新动画；
- 将全局背景改为蓝—紫—暖粉渐变，并把门户放入有圆角和深层投影的浅色应用框架；
- 将侧栏、顶栏、卡片、控件、工具弹层和文档阅读器统一为冷灰Soft UI表面；
- 使用双向柔影表达浮起按钮与卡片，使用内阴影表达搜索框、进度槽、筛选器和输入控件；
- 将主强调色收敛为皇家蓝，状态类信息保留绿色、琥珀和红色；
- 把ECharts坐标轴、提示框、标签和代表模型配色调整到浅色背景；
- 保留移动端无外框布局和`prefers-reduced-motion`动画降级。

## 3. 边界

本次只修改视觉语言和图表表现，不改变文档索引、模型数据、工具白名单、训练面板代理或
任何训练逻辑。参考图仅用于提取设计语言，没有复制其品牌、数据内容或业务结构。
