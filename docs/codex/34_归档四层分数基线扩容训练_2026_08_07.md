# 归档四层分数基线扩容训练

## 训练身份

- 模型：`baseline-scale-v1-l4-r1`；
- 代码：`baseline-scale-v1@f6edba2`，训练身份为干净工作区；
- 配置：4层物理GNN、128隐藏维度、876,734参数、1792环境、batch 768、BF16、编译模式；
- 奖励与物理：`score_v1`、30 FPS训练，120 FPS只用于最终评估；
- 训练量：16,001,280 transition、20,493次更新、54,469局。

## 最终效果

| 指标 | 30 FPS，4096局 | 120 FPS，4096局 |
| --- | ---: | ---: |
| 局均分 / 中位分 | 3742.69 / 3613 | 3471.08 / 3368 |
| 局均投放 / 合成 | 363.69 / 335.75 | 340.41 / 312.64 |
| 平均最高等级 | 10.614 | 10.512 |
| 终局水果数 | 27.88 | 27.73 |

相对3层`baseline-r1`，30/120 FPS局均分提高14.10%/13.68%；512局30 FPS贪心轨迹中，
7000分以上占比由0.78%提高到5.47%。4层模型替代3层模型成为当前效果基准。墙边投放占比
有所增加，但这是常见玩法，只记录为策略特征，不单独判为缺陷。

## 性能与证据边界

1M transition后的正式训练吞吐中位数为5353.23 transition/s，相对历史基线下降10.4%，
通过15%性能门禁。整轮训练、4096局双帧率评估、512局轨迹与Replay样本导出约77分钟。

本轮保持奖励、状态、动作、隐藏宽度和评估seed base不变，但环境数、batch和实际训练量
也发生变化。因此能够确认4层正式配置整体更优，不能把约14%的提升全部归因为增加一层
GNN。严格层数因果结论仍需同执行配置的3层成对训练。
