# 建立分层 Agent 导航与文档阶段索引

## 修改原因

仓库代码模块边界基本清晰，但根规则曾要求普通修改也广泛浏览 `docs/`、模型评估和旧分支。
`docs/README.md` 又平铺全部历史记录，使修改单个参数或局部界面时容易加载大量无关上下文，
并可能把旧文档中的“当前、默认、下一轮”误当成现状。

## 已完成

- 将根 `AGENTS.md` 收敛为全局约束和任务路由，普通参数、修复、UI 与工具修改不再触发
  模型历史审计；
- 在 `configs/`、`src/daxigua/core/`、`src/daxigua/simulator/`、`src/daxigua/rl/` 和
  `portal/` 增加局部 `AGENTS.md`，提供目标文件、边界和最小验证；
- 将 `docs/README.md` 从历史文件清单改为当前事实与按任务入口；
- 新增 `docs/STAGE_INDEX.md`，把 accelerated-v1 划分为 S0～S5，并记录旧实现的覆盖关系；
- 在 `docs/codex/`、`docs/model/`、`docs/model_evaluations/` 增加时效性规则，默认只读取
  当前阶段或目标模块最近阶段的一份相关文档；
- 给模型总览和比较矩阵增加历史快照提示，并修正门户、训练系统、辅助动作和物理身份入口
  中已经过时的“当前”描述；
- 保留历史文件原路径，不移动或批量改写记录，避免破坏既有链接与证据引用。
