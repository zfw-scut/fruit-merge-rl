# 统一训练与场景实验室门户

## 修改原因

训练面板、场景实验室和项目知识门户曾分别维护HTML页面。跨页面跳转、iframe和重复样式
导致训练字段难以折叠、场景控件拥挤，也让同一项能力存在多个显示入口。本次只重构展示层
和只读数据契约，不修改actor、learner、Replay、模型结构、奖励或物理计算语义。

## 已完成

- 在Xigua Atlas新增原生“实时训练”和“场景实验室”工作区；
- 删除训练服务中的内嵌`_DASHBOARD_HTML`和`scenario_lab_web.py`；
- `8765`、`8769`根路径改为`410`迁移提示，端口只保留API；
- 训练首页保留进度、吞吐、ETA、得分和GPU概览，其余指标按学习、性能、动作分布和事件
  折叠；
- 新增`runs/training_queue.json`只读契约，并把当前run的实时进度合入统一队列；
- 训练曲线改用ECharts原生折线图，加入漂亮刻度、底部滑块、Shift+滚轮、框选缩放和复位；
- 场景编辑、21动作Q值、辅助动作预测、真实物理验证、持续决策和图层设置全部进入门户；
- 工具中心启动场景或历史run后直接进入门户页面，不再打开旧显示；
- 历史run使用非默认端口时，门户代理跟随工具进程登记的URL。

## 队列与安全边界

面板只读取队列，不提供开始、停止、重排或覆盖训练的控制接口。队列由外部接力/调度脚本
原子写入，最多读取64项；损坏或缺失时降级为当前run。训练进程只多做轻量JSON读取，
不存在GPU到CPU的大量逐步采集，也不会进入训练热路径。

场景实验室API只向回环地址门户开放CORS。模型和物理仍在Python服务中执行，前端不会计算
替代奖励或伪造真实动作效果。
