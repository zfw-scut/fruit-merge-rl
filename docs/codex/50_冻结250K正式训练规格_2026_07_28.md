# 冻结 250K 正式训练规格（2026-07-28）

## 目的

把第一次结构感知 V2 大规模训练从候选 500k 收敛为一次可执行、可审计的 250k
正式训练，并保证探索曲线、配置门禁和输出身份都从 update 0 保持一致。

## 修改

- 正式基线冻结为 250000 updates 和独立 `_250k` run 目录。
- 新增 `configs/train_dqn_causal_250k.toml`；默认训练入口和 preflight 均使用它。
- 保留 500k 配置作为可选延长实验，并显式覆盖回 500000，避免名称与行为错位。
- preflight 契约改为当前正式训练契约，冻结 250k 长度、run 目录、smooth epsilon、
  H256/L4、16+6 worker、集中 actor、完整反事实和局部 Shapley。
- readiness 默认基线和测试切换到 250k；5k、旧 500k 配置不能冒充正式 preflight。
- 用户批准已经完整通过的独立 V2 10k 替代缺失的 V2 5k 顺序证据；最终提交上的
  全量测试、preflight、空目录和资源监控门禁不变。

## 启动约束

正式命令只允许：

```bash
CONDA_ENV=python-torch \
  ./scripts/train_dqn.sh configs/train_dqn_causal_250k.toml
```

首次启动不带 `--resume`、`--total-updates` 或 `--overwrite`。训练启动身份和实测
证据另行记录，避免在启动前把待验证事项写成完成状态。
