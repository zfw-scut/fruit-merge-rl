# 新增云端训练实时面板

## 修改原因

云端训练运行数十分钟到数天时，单独查看训练日志、指标 CSV、资源监控 CSV 和阶段
控制目录较为零散，也不便在本地持续观察评估曲线。项目需要一个轻量、只读且不会
干扰训练进程的统一页面。

## 主要修改

- 新增 Python 标准库 HTTP 服务，汇总训练 update、预计剩余时间、吞吐、loss、
  episode、评估结果、CPU/GPU/显存和资源监控事件。
- 面板支持显式指定 run、monitor、control 三个目录，也能自动发现最新落盘产物；
  读取 CSV 时忽略尚未完整写入的尾行。
- 只暴露稳定的状态/健康检查接口、固定静态资源和白名单训练曲线；不返回服务器绝对
  路径、配置凭据或任意训练文件。
- 新增简约动态前端，以原生 HTML/CSS/JavaScript 轮询状态并展示实时曲线，不依赖
  公网 CDN。
- 新增 Linux 生命周期脚本，用独立进程组运行面板，并在停止前校验 PID、进程启动
  时刻、命令行和工作目录。
- 默认只监听 `127.0.0.1:8765`，从本地通过 SSH 端口转发访问；面板不提供训练
  start、stop、resume、删除或参数修改能力。

## 涉及文件

- `tools/training_dashboard.py`：只读状态聚合和 HTTP 服务。
- `scripts/training_dashboard.sh`：面板启动、停止、重启和状态检查入口。
- `src/daxigua_rl/dashboard/static/index.html`：页面结构。
- `src/daxigua_rl/dashboard/static/styles.css`：布局、主题、响应式和动画样式。
- `src/daxigua_rl/dashboard/static/app.js`：状态轮询和前端图表。
- `tests/test_training_dashboard.py`：解析、敏感信息过滤和 HTTP 安全边界测试。
- `docs/operations/TRAINING_DASHBOARD.md`：部署、SSH 隧道、安全与排障手册。
- `README.md`、`docs/README.md`、`docs/project_map/PROJECT_FILE_INDEX.md`：
  补充项目入口和文件职责。

## 备注

- 面板只观察既有落盘数据，不参与训练语义、模型更新、checkpoint 或资源调度。
- 默认回环监听是安全边界的一部分；没有额外认证和受控反向代理时，不应改为公网
  `0.0.0.0`。
- 文档和脚本不保存 SSH 密码、私钥或其他凭据，认证继续由 OpenSSH 和云平台管理。
- 页面所显示的中间评估曲线仍属于训练中证据，不能替代阶段结束后的 readiness 和
  正式训练归档结论。
