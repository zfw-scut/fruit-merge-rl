# 重构场景实验室实时物理

## 修改原因

原型把“编辑场景”、“阻塞模拟至稳定”和“前端回放”串行绑定，导致下一次投放
必须等待前一颗水果稳定和回放完成。场景实验室需要改为与真实游戏一致的持续物理世界。

## 本版边界

- 后端保留单个持久化 Pymunk 世界，以120 FPS固定时步在独立线程推进。
- 投放、暂停、恢复、清空和载入场景通过命令队列在物理帧边界生效。
- 实时状态以60 FPS通过 SSE 发布；前端直接绘制当前世界，不生成或播放预计算轨迹。
- 运行态允许快速连续投放，不检查前一颗水果是否稳定；暂停态才开放几何编辑。
- Reward V2 评估复制点击时的位置、速度和角速度快照，不会暂停实时世界。

## 验证

- 连续两次投放在前一颗水果未稳定时均被接受。
- 暂停期间物理帧不增长，命令仍可被应用；恢复后从原状态继续推进。
- 浏览器实测可从水果列表连续拖入，预设载入会进入暂停编辑，且页面无运行时错误。

## 旧分支边界

旧分支只用于审计“渲染帧驱动持续物理”的游戏行为。本版没有引入旧分支运行依赖，
也没有复用其 Android 或模型观看器代码。
