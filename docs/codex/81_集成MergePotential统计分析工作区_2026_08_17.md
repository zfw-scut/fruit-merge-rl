# 集成 Merge Potential 统计分析工作区

## 修改原因

20,000局正式采集已经生成五张基础CSV，但逐表阅读不适合快速比较等级、时间窗口和条件
关系，也不利于未来其它统计任务复用。需要在Xigua Atlas内增加只读分析入口，同时保留
原始数据口径和证据边界。

## 已完成

- 门户新增“数据分析”页面和`#analysis`路由；
- 本地控制API发现`runs/analysis/*/analysis/analysis_manifest.json`，只读取清单与小型CSV，
  不加载原始张量分片；
- 数据响应统一为数据集元信息、表结构和结构化行；没有专用视图的新统计仍可使用通用表格；
- Merge Potential提供等级×时间窗口热图、等级生命周期表、单因素条件曲线、加权分箱关联
  强度、双因素联合热图和精确概率矩阵；
- 原始表格支持数据表与等级筛选、表内搜索、列排序、核心列/全部列和50行分页；
- 页面沿用现有Soft UI层级、ECharts更新动画、Framer Motion页面过渡和减少动态效果降级；
- 图表与表格在桌面和390像素窄屏下自适应，横向密集表格只在自身容器内滚动。

## 数据与解释边界

当前默认数据集是`SAB-128`在30 FPS、完整逐帧下落、无投放上限环境中的20,000局正式统计。
条件概率仍按原离线汇总口径：生命周期只取首次稳定观察，重复状态快照按每颗水果总权重1
归一化。页面中的“关联强度”表示同等级内加权分箱条件概率的分离程度，不是Pearson相关
系数，也不构成因果判断。

页面不重算或覆盖CSV；新增统计类型可以先沿用通用表格契约，再按需要增加专用可视化适配，
不要求为每个数据任务复制一套门户。

## 验证

- 门户服务单元测试9项通过，包含统计数据集发现、数值/缺失值解析和既有接口回归；
- 前端`npm run lint`通过；
- 前端`npm run build`通过；
- 真实20,000局目录被识别为1个数据集和5张分析表；
- 浏览器检查时间尺度、单因素、双因素和原始表格四个视图，等级筛选与分页生效；
- 桌面与390像素窄屏无页面级横向溢出，浏览器控制台无错误或警告。

这些验证证明数据读取、交互和展示正常，不表示模型能力、辅助任务精度或统计因果解释得到
提升。
