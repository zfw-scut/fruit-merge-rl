# Codex 修改记录规则

本目录记录 accelerated-v1 的重要结构变化，帮助后续开发者理解保留边界和验证结果。

以下情况需要新增记录：

- 新增、删除或重命名重要目录、公共契约或依赖；
- 开始实现模型、训练、模拟或性能管线；
- 修改水果领域规则或状态数据契约；
- 改变兼容性、运行方式或验证门禁。

纯文案、注释和格式调整通常不单独记录。

文件名使用连续编号、简短中文说明和日期：

```text
01_建立accelerated_v1最小基线_2026_08_01.md
02_新增某项能力_YYYY_MM_DD.md
```

每条记录至少说明：

- 修改原因；
- 保留、删除或新增了什么；
- 涉及的主要文件；
- 实际执行的验证及结果。
