# 重做合成反馈与中文 Q 版 UI

## 修改原因

Android 成品中的合成冲击环最高透明度只有约 22%，而且整层绘制在水果背后，实际
很容易被新水果遮住。AI 等待阶段还会把每帧颤动反写到当前位置形成随机游走，
拟人轨迹则每 26～81ms 硬切一次偏移，真机观感更像故障抖动。

同时，界面仍使用英文 Nunito，没有合成音效，也缺少一次投放内从“多处合成”到
“统一计入总分”的完整反馈。

## 主要修改

- 把合成特效改到水果上方绘制，并加入高可见度爆浆主体、放射尖角、彩色液滴、
  点状冲击环和短暂白色闪光。
- 为 11 个结果等级固定与水果贴图对应的爆浆色；连续事件按约 `0.105s` 错峰触发。
- 每个合成位置弹出同色 `+分值` 立体字，先上浮悬停；Box2D 确认同次投放不再
  产生连锁后，全部分值用 `p²` 加速曲线和不同弧线一起吸入左上计分卡。
- 合成事件保留两个源水果 ID 和结果水果 ID：只有前一次结果水果继续参与下一次
  合成时才增加连锁层级；同一投放内互不相干的两组合成不会被误判为二连锁。
- 计分卡在吸收完成时发光、震动并播放奖励音，显示分数再用快速 ease-out 从旧值
  滚到真实新值。规则分数仍在 `MergeEvent` 到达时即时更新，不影响 AI 快照。
- AI 与手动入口都要等物理稳定且上一组合成表现已经释放后才能再次投放；若多个
  已释放序列的滚分相遇，只保留最新累计目标，避免 HUD 动画队列长期落后。
- 游戏结束时不再等待已经停止推进的物理世界；待触发事件仍按原间隔播放，然后
  强制释放分值吸附，最终显示分数一定与规则分数收敛。
- 将队列、拟人轨迹和纯表现随机数拆为三套 `Random`，避免增加粒子后改变水果队列。
- AI 等待颤动改为固定锚点附近的低频有界偏移；拖动改为 ease-out 主体、低通过滤
  的相关噪声和低频微颤，取消高频硬切与纵向漂浮，最终投放仍回到模型规范列。
- 所有游戏内文案和 Android 应用名改为中文；引入站酷快乐体中文子集图集，标题、
  状态、卡片、操作提示、结束弹层和立体数字共用同一 Q 版字体纹理。
- 引入 Kenney Impact Sounds 的弹出、柔软冲击和奖励音三个 OGG；中大水果或连锁
  会叠加较低音量的柔软冲击，吸附完成播放短奖励音。
- Android 构建新增音效、字体和第三方许可证同步任务；OFL 与 CC0 原始许可证均
  进入 APK 的 `assets/licenses/`。
- Windows 真实渲染入口新增 `-Showcase -CaptureFrames N`，可复现爆浆、浮分、
  吸附和滚分阶段，不需要等待随机实战局面。

## 备注

桌面入口已实际加载同一字体、三个 OGG 和同一表现代码，但电脑无法替代手机扬声器、
震动马达与手指触控。最终仍应在一台真机上确认音量、连续合成听感和 AI 拖动手感；
这些只需要调表现常量，不涉及重新训练或修改模型。
