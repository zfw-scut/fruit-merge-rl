# 延长辅助动作模型 epsilon 探索

## 修改原因

首轮辅助动作完整配置在24M训练中取得明显效果提升，但epsilon在6.4M就从1.0降至0.05，
此时辅助预测仍在快速学习。旧Fast/Slow实验没有辅助预测、多策略头或不确定性主动学习，
不能直接证明同一衰减速度适合当前模型。下一轮先检验“辅助模型是否需要更长探索期”。

## 修改内容

- `configs/gnn_dqn_auxiliary_action_l5_24m.toml`的epsilon最低点由6.4M移至18M；
- epsilon仍从1.0线性衰减到0.05，并在18M～24M保持0.05；
- `epsilon_decay_fraction`同步由0.40改为0.75，与显式schedule语义一致；
- 奖励、模型、Replay、训练量、bootstrap、辅助loss权重和主动学习参数均不变。

保持`active_learning_epsilon_threshold = 0.08`会使主动学习启动点由约6.20M自然推迟到
约17.43M。因此本次实验实际比较的是“更长的epsilon探索期，同时更晚由不确定性动作替代
随机动作”，不能单独归因于总epsilon或主动学习启动时间。

## 历史边界

首轮`auxiliary-action-r1`的实际配置和模型报告继续保留6.4M最低点，不追溯修改。新schedule
只用于下一次从头训练；不得用它续写首轮run身份。

## 验证

- 加载TOML后检查epsilon在0M/18M/24M分别为1.0/0.05/0.05；
- 检查17.43M附近穿过0.08主动学习阈值；
- 执行配置与epsilon相关测试。
