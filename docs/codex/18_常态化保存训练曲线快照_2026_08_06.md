# 常态化保存训练曲线快照

## 修改原因

实时面板已经能在浏览器 Canvas 中查看分数、Loss 和吞吐历史，但曲线只存在于页面内存，
训练结束或服务器关闭后不能直接作为标准图片归档。云端训练也需要用较低频率更新完整
曲线图片，方便远程确认长时间趋势，同时不能把 Matplotlib 和全量日志读取放进训练热路径。

## 新增能力

- 新增 `src/daxigua/rl/curves.py`，从持久化训练与评估 JSONL 生成标准 2×2 PNG；
- 图片固定保存为 `plots/training_curves.png`，并以临时文件加 `os.replace` 原子替换；
- `plots/training_curves.json` 记录生成时间、覆盖 transition、数据点数、文件大小和中文字体状态；
- 独立面板进程默认每 120 秒更新一次，首次无数据时以 15 秒间隔重试；
- 30/120 FPS 评估完成后请求旁路刷新，正常训练收尾时等待最终图片完成；
- 面板新增只读白名单图片接口和自动破缓存展示区，重启后可从已有元数据恢复；
- 最终产物清单纳入 PNG，关闭云服务器前可与 checkpoint、JSONL 一起校验迁回；
- 云端 preflight 会生成一张最小 PNG 并检查文件签名，提前发现 Matplotlib 或字体环境故障；
- 新增 `--curve-snapshot-interval` 和 `--disable-curve-snapshots` 运行参数。

## 性能边界

训练主进程仍只按原节奏写紧凑 JSONL，不导入 Matplotlib、不读取历史文件，也不参与周期
绘图。绘图、字体扫描和 PNG 压缩都在面板旁路进程执行；单次失败只在面板显示错误，不会
终止训练。默认只覆盖一张最新图片，避免按时间无限累积 PNG 占用磁盘。

## 验证

- Python 编译检查覆盖曲线、监控、配置、trainer 和训练入口；
- 使用第一轮 RTX 5090 的 260 条训练指标与 6 条评估记录实际生成 PNG；
- 核对图片包含平均分/双帧率评估、窗口最高分、优化信号和吞吐四个区域；
- 单元测试覆盖不完整 JSONL 尾行、PNG 签名、元数据恢复、临时文件清理和面板状态字段。
