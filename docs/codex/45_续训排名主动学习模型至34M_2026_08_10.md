# 续训排名主动学习模型至 34M

## 1. 目的与证据边界

24M 排名主动学习训练的训练窗口均分在后四个区间仍缓慢抬升：16～18M、18～20M、
20～22M、22～24M 的窗口均值依次约为 3250、3268、3317、3363。因此追加约 10M
transition，用于观察当前结构在固定低 epsilon 和高主动学习占比下是否仍有策略收益。

上述趋势只是训练分布观察，不证明独立 greedy 策略必然继续提高。34M 完成后仍须使用相同
seed 的 4096 局 30/120 FPS 评估，与 24M 父 run、辅助动作首轮模型和 5 层 Fast 基线
分别比较，不以 loss、训练窗口分数或单次 512 局周期评估替代最终结论。

## 2. 父 run 与续训语义

- 父 run：`runs/cloud_rtx5090_auxiliary_action_rank_active_faa1377_seed20260809_24m`；
- 恢复点：父 run 的 `checkpoints/final.pt`；
- 父 run 完成进度：24,000,768 / 24,000,000；
- 父 run 最终评估：30 FPS 4226.63，120 FPS 3949.27，各 4096 局；
- 正式续训 run：
  `runs/cloud_rtx5090_auxiliary_action_rank_active_continuation_c01cedb_seed20260809_34m`；
- 目标累计 transition：34,000,000，即从父 checkpoint 实际追加约 9.999M；
- 续训代码：`c01cedb`；
- 云端启动 PID：`12947`。

恢复内容包括 online/target 模型、Adam optimizer、PyTorch/Python RNG、累计 transition、
episode、update 和历史最佳评估。当前 checkpoint 明确使用 `replay_resume_policy=rebuild`，
不会保存 Replay 样本；续训启动时重新构造 262,144 条分阶段 Replay。因此本轮属于“模型、
优化器和计数连续，Replay 重建”的续训，不应描述为逐样本或逐物理状态无缝恢复。

## 3. 续训参数

- 模型、奖励、辅助 loss、bootstrap、环境数、batch、学习率和 UTD 均保持父 run 配置；
- epsilon 在 24M 以后保持 0.05，不重新抬高；
- 主动学习保持排名融合 Top-4；
- 低 epsilon 阶段三分支为主动学习 40%、epsilon 随机 5%、贪心 55%；
- 最终仍执行 4096 局 30 FPS、4096 局 120 FPS 和关键事件分析；
- 使用新的 run 目录，不覆盖父 run 的 checkpoint、曲线和评估产物。

## 4. 恢复缺陷与修复

第一次续训启动在任何训练更新发生前失败。`trainer.resume()` 使用
`load_checkpoint(..., map_location='cuda')` 后，checkpoint 中原本属于 CPU 的 RNG sidecar
也被映射到 CUDA；`torch.set_rng_state()` 只接受 CPU ByteTensor，因此触发：

```text
TypeError: RNG state must be a torch.ByteTensor
```

修复提交 `c01cedb` 在 RNG 恢复接口边界把 CPU/CUDA RNG sidecar 显式归一化到 CPU，再
调用 PyTorch 恢复接口，并增加 CUDA 映射 checkpoint 的回归测试。`test_rl_baseline` 24 项
通过；云端部署后两项 checkpoint 恢复门禁通过。第一次失败目录保留为故障证据：

```text
runs/cloud_rtx5090_auxiliary_action_rank_active_faa1377_seed20260809_continued_34m
```

该目录没有进入 Replay 预热或 optimizer update，不属于有效实验数据。

## 6. 完成、评估与本地迁移

`【事实】` 正式续训正常完成 34,000,128 transition 和 65,894 次更新。最终 4096 局
30/120 FPS 均分为 4493.78/4183.56；相对 24M 父模型的 4226.63/3949.27 分别提高
6.32%/5.93%。该提升证明本次 24M 后仍有训练空间，但不能单独归因于排名主动学习。

`【事实】` 24M 父 run 与 34M 续训 run 均已完整迁回本地。外层归档分别为
296,324,238/207,815,212 字节，SHA-256 分别为
`4ba697f38843eec970ea50856210edad874b862b006a9dc650fdaa425620aa28` 与
`eae5f196eb49ef6c27719b6369cef9b6e7de2f26f9d5c138d888d6c911efd346`；本地与云端一致。
解包后分别有 27/22 个文件和 1,223,147,365/1,157,448,752 字节，内部 manifest
23/23、18/18 精确匹配。两组 `best.pt` 与 `final.pt` 均通过本地加载。

`【决策】` 辅助动作首轮 24M 的 4849.65/4476.35 仍是当前效果领先结果。排名主动 34M
虽超过5层Fast，但多使用约10M transition后仍低于辅助首轮7.34%/6.54%，因此不升级为
默认；下一步优先做同checkpoint的主动40%对0%后期续训消融。完整分析见
`model_evaluations/model-auxiliary-action-rank-active-r3.md`。
