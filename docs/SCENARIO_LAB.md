# 自定义场景实验室

- 状态：前端第一版已实现，真实物理、模型推理和奖励计算尚未接入
- 用途：用鼠标快速构造极端局面，并为后续同场景 21 动作并行评估提供稳定入口
- 入口：`tools/open_scenario_lab.py`

## 当前能力

- 左键放置水果，拖动调整位置，右键或删除工具移除水果；
- 鼠标滚轮切换当前或选中水果等级；
- 11 级水果贴图、真实显示半径、危险线、空间网格和 21 个动作锚点；
- 场景撤销与重做，q0～q3 队列编辑，30/120 FPS 评估参数；
- 濒临出界、底层缺口、同级堆积和空白场景预设；
- 重叠与越线几何提示、最多 64 个水果限制；
- 自包含 JSON 导入导出，不依赖外部前端框架或网络资源；
- 结果页和 21 动作奖励图已经保留，但没有真实结果时只显示明确空状态。

## 交互和视觉原则

场景画布始终是页面视觉中心。左侧只保留编辑工具和水果选择，右侧按“场景设置”和
“评估结果”分离信息，避免同时铺开大量指标。颜色、圆角、半透明表面和控件状态采用
Windows 11 Fluent 方向；危险、重叠和后端未连接使用不同层级提示，不靠大段文字抢占
场景空间。

## 后端边界

前端点击“运行至稳定”或“评估 21 个动作”时会派发
`daxigua:scenario-request`，其中包含场地、场上水果、q0～q3、物理帧率和投放探针。
页面同时暴露只用于后续本地适配层的 `window.daxiguaScenarioLab` 接口，可读取或载入
场景、更新后端连接状态并写入真实评估结果。

当前版本不会在 JavaScript 中重写一套简化物理，也不会生成演示奖励。下一阶段应由本地
Python 服务校验场景、重建所有派生物理属性，并调用同一 CUDA 模拟器和 checkpoint。

## 使用

```powershell
$env:PYTHONPATH = 'src'
& $python tools\open_scenario_lab.py --open
```

不传 `--open` 时只在 `recordings/scenario-lab/index.html` 生成自包含页面，便于手动打开
或归档视觉版本。
