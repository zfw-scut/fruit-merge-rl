## 1. 状态说明

| 标记 | 含义 |
| --- | --- |
| 已确认 | 算法方向已经讨论通过，具体尺寸和参数仍可留到实现阶段 |
| 部分确认 | 核心方向已定，仍有关键接口或训练目标未定 |
| 待讨论 | 已提出但尚未确认 |
| 暂缓 | 当前主动推迟，后续结合训练结果再决定 |
| 不采用 | 已明确排除，不应进入新模型 |

当前仓库已经实现第一版 GNN-DQN 基线、正式训练系统和可开关的动作效果辅助任务；
战略 Pair Encoder、高层规划、FiLM 和 BMCTS 仍未实现。表中的“已实现（基线）”只表示第一版低层
基线具备该能力，不能理解为后续完整分层模型已经完成。

物理水果边采用以下候选并集：全部真实接触边、半径感知近邻边、即将碰撞的运动边、
最近纵向影响边，以及墙壁/地面边。动作探针采用“全水果轻量软聚合 + 关键水果精细
消息”。

## 6. 模型输入取舍

| 类别 | 元素 | 状态 | 说明 |
| --- | --- | --- | --- |
| 保留 | 位置、线速度、角速度、等级、物理半径、质量 | 已确认 | 进入物理水果节点 |
| 暂留 | 压缩后的 `age_frames` | 待消融 | 可能帮助识别新生成和仍在演化的水果 |
| 派生 | 稳定标志、危险线距离、墙/地净空、接近速度 | 已确认 | 从原始状态确定计算，不重复维护 |
| 掩码/标签 | `active`、`fruit_id`、`done` | 不作为特征 | 只用于有效性、事件追踪和训练边界 |
| 删除 | 绝对旋转角度 | 不采用 | 圆形水果的碰撞几何与绝对角度无关 |
| 删除 | 累计分数、上一分数、步数、绝对物理帧 | 不采用 | 不改变当前物理转移，避免时间和局长捷径 |
| 全局摘要 | `fruit_count/max_level/max_height/empty_space_ratio` | 待消融 | 不重复写入水果节点，可由聚合得到 |
| 新增 | `danger_progress`、当前越线标志 | 已确认 | 已加入批量观察、TensorState 和 Replay |

| 元素 | 状态 | 原因或替代方案 |
| --- | --- | --- |
| `codex/work-1` 旧模型与训练栈 | 不采用 | 旧分支只用于只读经验审计，不迁移模型依赖 |
| 原“关系视角/几何视角”粗略划分 | 不采用 | 改为全局战略结构视角与动作条件化效果视角 |
| 旧式动态 motif、重型状态分析和因果归因 | 不采用 | 使用数量聚合、Pair Encoder、区域和真实事件监督 |
| 战略边按可联通概率硬删除 | 不采用 | 训练早期保留软边、原因和不确定性 |
| 动态区域聚类或硬互斥区域 | 不采用 | 使用 7 个固定锚点和水果软归属 |
| 完整二维区域网格/垂直区域节点 | 不采用 | 垂直方向进入每个横向锚点的摘要 |
| 物理水果全连接图 | 不采用 | 使用接触、近邻、运动和纵向边的混合局部图 |
| 仅接触物理图 | 不采用 | 会遗漏即将碰撞和非接触纵向影响 |
| 为 21 个动作复制 21 张完整图 | 不采用 | 一张共享物理图 + 21 个并行动作探针 |
| 动作探针回写水果或动作间传消息 | 不采用 | 保持 21 个反事实动作相互隔离 |
| 基线使用 3-step 或更长多步回报 | 不采用 | 相邻投放不做直接多步奖励归属；使用 1-step TD bootstrap |
| 原始合并债务直接作为奖励 | 暂不采用 | 先用于表示、计划、辅助监督和评估 |
| 基础训练期间使用 BMCTS | 不采用 | BMCTS 只用于评估、正式使用和后期可选蒸馏 |
| 固定人工显式计划类型集合 | 暂缓 | 后续比较人工计划、模型潜在计划和混合方案 |
| 永久缝隙/通道节点 | 待讨论 | 可能改为与区域关联的临时结构候选 |
| 未执行动作的真实结果监督 | 不采用 | 当前只监督实际动作；未来关键状态多动作标签必须来自反事实推演 |
