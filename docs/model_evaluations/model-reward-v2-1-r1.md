## 2. 已确认效果

| 指标 | 30 FPS，4096局 | 120 FPS，4096局 |
| --- | ---: | ---: |
| 局均分 / 中位分 | 2555.24 / 2477.5 | 2341.71 / 2293 |
| 分数标准差 | 575.80 | 550.54 |
| 局均投放 | 268.92 | 251.26 |
| 局均合成 | 232.69 | 214.13 |
| 合成数 / 投放数 | 0.8653 | 0.8522 |
| 平均最高等级 | 10.044 | 9.855 |
| 终局水果数 | 36.23 | 37.13 |
| 危险投放率 | 9.21% | 9.62% |
| settle timeout率 | 0.205% | 0.284% |
| 最外侧 A0+A20 | 36.91% | 36.03% |
| 外侧四动作 A0+A1+A19+A20 | 43.66% | 42.46% |

- `【事实】` 相对 Reward V2，V2.1在30 FPS提高29.56分（+1.17%），独立样本近似
  95%区间为`[4.79, 54.33]`；120 FPS提高32.04分（+1.39%），区间为
  `[8.61, 55.48]`。4096局评估能够识别这次小幅差异，但单训练seed不能证明可复现增益。
- `【事实】` 相对分数基线，V2.1仍在30 FPS低725.05分（-22.10%），120 FPS低
  711.72分（-23.31%），没有达到替代基线的条件。
- `【事实】` 30→120 FPS分数下降8.36%；Reward V2为8.55%，分数基线为6.92%。
- `【事实】` 相对Reward V2，30 FPS局均投放增加2.47、局均合成增加2.05，但合成/投放
  比例由0.8656微降至0.8653，终局水果数反而增加0.43。改善主要表现为略长的存活局长，
  没有形成更高的合并效率。
- `【事实】` 最终4096局30 FPS评估中，最外侧动作占比由Reward V2的30.72%升至
  36.91%，比基线29.36%高7.56个百分点。
- `【决策】` 墙边投放是合成大西瓜的常用策略，外侧动作占比升高本身不作为模型缺陷或
  得分退化原因；只有固定场景显示它破坏合成机会时才能形成负面结论。
- `【决策】` V2.1保留为“奖励基线校正成功、策略目标仍未对齐”的中间实验，不替代
  `baseline-r1`，也不直接扩展为更大模型训练。

## 3. 奖励与动作证据

离线分析使用均匀抽取的131,072条Replay transition。这里把非终局且水果数增加1定义为
“近似无合成”，把非终局且水果数不增加定义为“近似发生合成”；后者是结构代理标签，
不是模拟器保存的谱系真值。

| Replay统计 | Reward V2 | Reward V2.1 |
| --- | ---: | ---: |
| 全部奖励均值 | +0.02057 | +0.00633 |
| 全部正 / 负奖励率 | 98.00% / 2.00% | 53.67% / 45.89% |
| 近似无合成奖励均值 | +0.01098 | -0.00201 |
| 近似无合成正 / 负奖励率 | 97.43% / 2.57% | 37.22% / 62.39% |
| 近似合成奖励均值 | +0.03137 | +0.01618 |
| 近似合成正 / 负奖励率 | 98.74% / 1.26% | 73.29% / 26.36% |
| 合成与无合成均值间隔 | 0.02039 | 0.01819 |

- `【事实】` V2.1消除了固定补偿造成的系统性正奖励：最终50个训练窗口正奖励率均值
  由98.06%降至53.61%，Replay无合成样本均值也已转负。
- `【事实】` 奖励重新居中后，“近似合成”与“近似无合成”的均值间隔没有扩大，反而从
  0.02039略降至0.01819。约26.36%的近似合成transition仍得到负奖励。
- `【事实】` V2和V2.1的补偿/参考损失在给定状态与当前水果后都是所有实际动作共用的
  标量，因此它们能改变奖励基线和长期状态价值，却不能直接修复同一状态下
  `L_actual`对21个动作的即时排序。
- `【事实】` V2.1无合成样本中，A0和A20平均奖励分别为-0.00026和-0.00049，中央附近
  A10和A12分别为-0.00331和-0.00358；外侧普通投放受到的惩罚明显更小。
- `【事实】` 512局最终贪心轨迹中，前32次投放的两侧动作占42.05%，32～63次为
  42.98%；当前水果为最小等级时两侧占52.00%。Reward V2对应最小等级两侧占36.20%。
- `【事实】` 30 FPS settle timeout率从Reward V2的0.076%升至0.205%，120 FPS从
  0.083%升至0.284%。绝对比例仍低于0.3%，现有证据不能把变化归因于墙边投放。

## 4. 性能证据

- `【事实】` 相同1792环境、batch、BF16和编译配置的成对热路径门禁中，`score_v1`
  中位吞吐为8601.26 env steps/s，`spatial_v2_1`为8527.71 env steps/s，净下降0.855%，
  通过5%警告和8%阻断门限。
- `【事实】` 正式训练1M transition后的窗口中位吞吐为4536.88 env steps/s；GPU利用率
  中位数99%，显存稳定为25,778MB / 32,607MB（约79.1%），GPU资源已充分使用。
- `【事实】` 主训练窗口约60分钟，完成13.143M transition；4096局双帧率评估、512局
  决策轨迹和131,072条Replay样本使总运行时间约78分钟，符合1～2小时训练周期。

## 5. 已确认不足

1. 奖励符号分布恢复正常，但真实分数只提高约1%，仍比基线低22%～23%。
2. 约四分之一近似合成transition被空间奖励判为负，说明“触发合成”不保证空间代理改善。
3. 合成/投放比例和终局水果数没有改善，尚未学到更好的清理与合成链策略。
4. 静态垂直走廊仍不表达同级对齐、横向可联通、滚动趋势、缺口堵塞或长期合成链。
5. 内部`artifact_manifest.json`生成后，面板又向`monitoring.jsonl`追加了272字节的
   `training_finished`事件；外层迁移归档哈希一致，数据没有丢失，但清单写入顺序应修复。

## 6. 原因假设

| 假设 | 置信度 | 支持证据 | 反对证据 | 反证或验证方式 |
| --- | --- | --- | --- | --- |
| V2.1只校正状态奖励基线，没有修复21动作排序，所以效果增益有限 | 高 | 参考损失对实际动作是共同标量；合成/无合成间隔没有扩大 | 长期状态基线仍可能改变策略 | 对固定状态保存21动作V2/V2.1排序；理论上即时排序应一致 |
| 外侧动作增加导致本轮得分退化 | 低 | 最外侧动作36.91%，高于历史模型 | 墙边投放是常用策略；没有固定场景证据证明该行为有害 | 仅在固定场景显示墙边动作破坏合成机会时重新提高置信度 |
| 空间代理对部分合成给负奖，阻碍主动构造合成链 | 中高 | 近似合成样本26.36%为负，合成效率未提高 | 水果数变化标签不等同精确谱系；部分合成后局面确实可能更差 | 保存q0谱系和真实合成事件，按合成等级/连锁长度分层奖励 |
| V2.1的约1%提升只是训练随机性 | 中 | 只有一个训练seed，周期评估存在明显波动 | 同seed base的4096局30/120 FPS均小幅领先V2 | 至少增加一个训练seed，或做较短成对复现实验 |
| 训练量差异是22%基线差距的主因 | 低 | V2.1实际训练量比基线少9.24% | 得分差距22%且结构指标同步退化；V2与V2.1训练量接近 | 同transition继续训练；若仍低约20%即可反证 |

## 7. 下一轮最低实验

- `【建议一】` 暂停Reward V2系列，恢复`score_v1`作为训练奖励，先单独检验基础GNN容量。
- `【建议二】` 第一轮只把物理消息传播由3层增至5层，保持128隐藏维度和其余结构不变；
  若云端性能门禁不合格则退至4层，不同时增加宽度。
- `【建议三】` 把真实q0谱系和合成等级加入离线分析标签，验证26.36%负奖励近似合成中
  哪些是真合成、哪些是终局前移除或其他水果运动造成的水果数变化。
- `【建议四】` 扩容实验仍采用约1～2小时、同seed base和最终4096局双帧率评估，并让实际
  transition尽量达到历史基线的14.5M以上。

## 8. 证据边界

本轮只有一个训练seed。V2与V2.1使用相同模型、评估seed base和4096局最终评估，实际
transition分别为13.387M与13.143M，比较较接近；分数基线为14.481M、1856环境且最终
仅1024局，不能把全部差异严格归因于奖励。均值差区间只覆盖评估采样误差，不包含训练
随机性。Replay样本来自训练期探索策略，不等于最终贪心策略分布；“近似合成”标签由水果
数量变化推断，不是谱系真值。
