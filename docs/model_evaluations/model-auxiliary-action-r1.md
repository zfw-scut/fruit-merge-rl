| 标准差 | 1960.84 | 1547.74 | 1722.33 | 1299.85 |

| 最大分 | **11907** | 11829 | **11751** | 11357 |
| 局均投放 / 合成 | **455.94 / 429.86** | 407.54 / 380.80 | **423.94 / 398.14** | 375.84 / 349.20 |
| 合成 / 投放 | **0.9428** | 0.9344 | **0.9391** | 0.9291 |
| 平均最高等级 | **10.835** | 10.747 | **10.777** | 10.653 |

| 最外侧A0+A20 | **35.20%** | 46.41% | **34.51%** | 45.83% |

- `【事实】` 30 FPS均值提高581.51（+13.62%），同seed成对95%区间为
  `[506.29, 656.73]`；辅助配置在61.72%的对局胜出，成对分差中位数为336。
- `【事实】` 120 FPS均值提高579.06（+14.86%），同seed成对95%区间为
  `[513.47, 644.65]`；辅助配置在62.38%的对局胜出，成对分差中位数为357。
- `【事实】` 辅助配置30→120 FPS均值下降7.70%，基线下降8.69%；前者相对迁移损失
  少0.99个百分点，同时120 FPS绝对分更高。
- `【事实】` 辅助配置的标准差更大，但中位数、P90、P95和最大值均提高；这主要表现为
  高分右尾增加，不能仅凭标准差升高写成策略不稳定。
- `【决策】` 把该完整配置登记为当前效果领先配置；保留5层Fast作为结构更简单的因果
  对照，直至第二训练seed复现和模块消融完成。

| 发生L11消除后的局均分 | **8363.33** | 7824.17 | +539.16 |

| 120 FPS，4096局 | 辅助配置 | Fast基线 | 差值 |
| --- | ---: | ---: | ---: |
| 5000+ | 697 / **17.02%** | 375 / 9.16% | +7.86个百分点 |
| 7000+ | 545 / **13.31%** | 251 / 6.13% | +7.18个百分点 |
| 10000+ | 81 / **1.98%** | 21 / 0.51% | +1.46个百分点 |
| 生成过L11 | 3358 / **81.98%** | 2871 / 70.09% | +11.89个百分点 |
| L11消除 | 642 / **15.67%** | 343 / 8.37% | +7.30个百分点 |

- `【事实】` 30 FPS的5000+、7000+、10000+和L11消除率成对差的95%区间均不跨0；
  7000+和L11消除分别增加8.23、7.37个百分点。
- `【事实】` L9/L10/L11每千次投放生成密度由基线的19.708/8.018/2.599提高到
  20.403/8.694/2.952。提升不只来自局变长，按投放数归一化后仍存在。
- `【观察】` 完整配置既更频繁进入L11消除事件，事件发生后的条件均分也更高；这与Fast
  相对Slow主要提高事件进入率的表现不同。
- `【假设】` 辅助效果表征改善了长合成链所需的局部动作排序。置信度中等；支持证据是
  合成效率、高等级密度和L11消除同时上升，反证条件是关闭辅助loss但保留多头/主动探索后
  仍得到等量提升。

## 4. 辅助任务、分歧与主动探索诊断

| 训练诊断 | 1M～3M中位数 | 21.6M后中位数 | 解释 |
| --- | ---: | ---: | --- |
| DQN loss | 0.02363 | 0.02798 | 后期未下降，不能单独判断策略退化 |
| 辅助总loss | 0.29332 | 0.12656 | 下降56.9% |
| 合成组 | 0.56188 | 0.26250 | 下降53.3% |
| q0谱系组 | 0.45562 | 0.19313 | 下降57.6% |
| 首次接触组 | 0.14600 | 0.06599 | 下降54.8% |
| 新水果组 | 0.28304 | 0.09891 | 下降65.1% |
| 结果组 | 0.02034 | 0.01031 | 下降49.3% |
| 策略头分歧 | 0.00815 | 0.02081 | 未塌缩，但量纲随Q尺度变化 |
| bootstrap有效率 | 0.80002 | 0.80016 | 符合0.8配置 |
| 主动学习动作率 | 0 | 3.75% | 符合0.05×0.75预算 |

- `【事实】` 后期加权辅助项约为`0.05 × 0.12656 = 0.00633`，约占DQN与加权辅助
  两项之和的18.4%；首轮0.05权重没有让辅助项主导总loss。
- `【事实】` 主动学习只替换epsilon探索预算中的动作；最低epsilon阶段实际比例约3.75%，
  与配置期望一致，没有额外增加总探索率。
- `【事实】` 策略头分歧未塌缩。其数值随Q值尺度增长，尚未做误差校准，因此不能把后期
  分歧升高直接解释为认知不确定性升高。
- `【假设】` 主动探索提高了稀有高价值轨迹的发现率。置信度低到中；当前没有“多头+辅助、
  关闭主动探索”的成对训练，不能把高分尾部增益单独归因于主动学习。

## 5. 训练性能与代价

| 指标 | 辅助配置 | Fast基线 | 变化 |
| --- | ---: | ---: | ---: |
| 参数量 | 1,210,451 | 1,028,045 | +17.74% |
| 1M后吞吐中位数 | 3486.53/s | 4589.43/s | -24.03% |
| updates/s中位数 | 13.62 | 12.00 | batch不同，不直接作算法效率结论 |
| learner总采样量 | 约23.74M | 约23.74M | 基本一致 |

`【事实】` 两组UTD均为1。辅助配置以更小batch进行更多次更新，`92,730×256`与
`61,820×384`的总采样量基本一致；不能把更新次数更多误写为训练数据量更多。

`【决策】` 24%的吞吐代价换得约14%的最终分数提升，当前可接受为效果领先配置；后续优化
优先降低辅助标签Replay、五头读出和learner的开销，不以删除监督目标换吞吐。

## 6. 结论边界与下一步

1. `【方案一｜采用】` 将该配置作为后续辅助动作与反事实框架开发的当前效果领先起点；
   训练和部署默认仍保留开关，可随时回到5层Fast简洁基线。
2. `【方案二｜必须复现】` 使用完全相同配置补第二个训练seed。若30/120 FPS均继续稳定
   超过Fast，再升级为跨seed稳定基准。
3. `【方案三｜最小因果消融】` 需要判断收益来源时，依次比较“仅多头”、“多头+辅助”与
   “多头+辅助+主动探索”；在此之前只称“完整配置收益”，不称“辅助动作净收益”。
4. `【方案四｜不立即改参数】` 当前0.05辅助权重、0.8 bootstrap和3.75%后期主动动作率
   均工作正常，下一轮复现前不同时调整，避免再次混入多个变量。
