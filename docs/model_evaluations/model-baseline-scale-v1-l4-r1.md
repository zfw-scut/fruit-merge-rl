## 2. 已确认效果

| 指标 | 30 FPS，4096局 | 120 FPS，4096局 |
| --- | ---: | ---: |
| 局均分 / 中位分 | 3742.69 / 3613 | 3471.08 / 3368 |
| 分数标准差 | 1118.35 | 964.82 |
| 局均投放 | 363.69 | 340.41 |
| 局均合成 | 335.75 | 312.64 |
| 合成数 / 投放数 | 0.9232 | 0.9184 |
| 平均最高等级 | 10.614 | 10.512 |
| 终局水果数 | 27.88 | 27.73 |
| 危险投放率 | 7.94% | 8.38% |
| settle timeout率 | 0.144% | 0.190% |
| 最外侧 A0+A20 | 33.07% | 32.90% |

- `【事实】` 相对`baseline-r1`，30 FPS局均分提高462.40（+14.10%），独立样本近似
  95%区间为`[405.64, 519.15]`；120 FPS提高417.65（+13.68%），区间为
  `[363.90, 471.40]`。评估采样误差不足以解释本轮差异。
- `【事实】` 30 FPS中位分提高11.75%，120 FPS提高10.16%；提升不只由少数最高分样本
  造成。30 FPS合成/投放由0.9110提高到0.9232，终局水果数由28.90降至27.88。
- `【事实】` 等样本的512局30 FPS贪心轨迹中，7000分以上占比由`baseline-r1`的
  0.78%提高到5.47%，5000分以上由2.34%提高到6.84%；对应最大分由7846提高到8396。
  高分模式变得更常见，但最终贪心轨迹仍不能支持“稳定产出7000+”的结论。
- `【事实】` 训练探索轨迹最高分为11,290；它证明训练过程到达过该状态分布，不等同于
  最终贪心策略可稳定复现一万分。
- `【事实】` 30→120 FPS局均分下降7.26%，旧基线为6.92%，帧率迁移损失扩大约0.34个
  百分点，但120 FPS绝对效果仍明显高于旧基线。
- `【决策】` 本模型替代`baseline-r1`，成为后续模型、奖励和规划升级的当前真实游戏
  效果基准；`baseline-r1`继续保留为3层历史对照。

- `【事实】` 5层候选在RTX 5090门禁中相对3层吞吐下降27.8%，显存投影35,079.5 MB，
  因而按预案回退到4层；4层、batch 768的门禁吞吐下降11.5%，显存投影25,703.5 MB，
  通过15%吞吐与85%显存门禁。
- `【事实】` 正式训练1M transition后的吞吐中位数下降10.4%，但完整16M训练、4096局
  双帧率评估、512局轨迹与131,072条Replay样本导出均在约77分钟内完成，符合1～2小时
  云服务器周期。
- `【事实】` 当前运行完成20,493次batch 768更新；历史基线完成7934次batch 1792更新。
  两者Learner处理的样本总量接近但不相同，不能用更新次数本身解释效果。

## 4. 已确认不足

1. 30→120 FPS损失略高于旧基线，模型仍对训练物理帧率存在分布敏感性。
2. 30 FPS分数标准差由738.88增至1118.35，高分尾部增强的同时，局间波动也扩大。
3. 最外侧动作占比由29.36%升至33.07%；墙边投放是常用策略，只记录为行为变化，不能
   单独判为缺陷。
4. 本轮同时改变GNN深度、batch、环境数和实际训练量，因此不是严格的单变量传播层数消融。
5. 模型仍只有一步分数奖励和局部物理图，没有显式合成链、长期计划、可联通性或动作
   效果辅助监督。

## 5. 原因假设

| 假设 | 置信度 | 支持证据 | 反对证据 | 反证或验证方式 |
| --- | --- | --- | --- | --- |
| 更深的物理消息传播是效果提高的主要来源 | 中高 | 奖励、隐藏维度、状态、动作和seed base保持不变；接近历史训练量时的周期评估也已明显超过旧基线 | batch、实际训练量和训练时长同时变化 | 以4层正式执行参数重跑3层16M成对对照 |
| 更大的Learner样本预算解释了大部分提升 | 中低 | Learner处理样本总量提高10.7% | 30/120 FPS得分提高约14%，且模型容量和传播范围同时提高 | 固定层数，仅匹配两轮Learner样本预算 |
| 高分能力已经学会，但平均分被偶发失败压低 | 中 | 512局中7000+频率显著提高，训练出现11,290分样本 | 7000+仍只有5.47%，中位分3613，不能称为稳定策略 | 固定seed保存高低分配对轨迹，比较首次不可逆结构失误 |
| 120 FPS损失来自30 FPS训练物理的分布偏移 | 中高 | 仅切换评估帧率即下降7.26% | 120 FPS绝对分仍提高13.68% | 后续单独做少量混合帧率微调或帧率随机化消融 |

## 6. 下一轮最低实验

- `【建议一】` 先保留4层、128隐藏维度和`score_v1`作为新基准，不立刻叠加宽度、奖励
  或辅助任务。
- `【建议二】` 若需要严格确认层数因果，只做一次3层、1792环境、batch 768、同16M预算
  的成对训练；若云成本优先，可暂不补跑，但后续文档不得把14%全部写成层数净收益。
- `【建议三】` 下一次模型升级继续使用4096局30/120 FPS最终评估，并常态化保存512局
  决策轨迹；增加固定seed高分/低分轨迹对照，以定位平均分与高分尾部的差距。
- `【建议四】` 扩容下一步只比较隐藏维度128→160，或者只增加战略/辅助模块，二者不要
  在同一轮同时修改。

## 7. 证据边界

本轮与历史基线都只有一个训练seed。两轮评估seed base相同，但历史基线每个FPS仅1024局，
本轮为4096局；均值区间只包含评估采样误差，不包含训练随机性。512局轨迹比较采用相同
样本规模，可用于描述最终贪心策略的高分频率，不能由训练窗口最高分推断稳定产出能力。
本轮运行的奖励、状态、隐藏宽度和动作语义保持不变，但环境数、batch、实际transition、
更新次数和总训练时长不同，因此确认的是“4层正式配置整体优于历史3层基线”，不是严格的
单因素因果结论。
