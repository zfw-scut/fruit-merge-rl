# 当前模型横向比较

> 本矩阵现有数值除1.6节外全部属于旧“合成水果继承动量”物理规则。2026-08-11之后采用
> 零初速度规则产生的新训练与评估需要明确标注物理分布变化，不能把分差直接归因于模型算法；
> 1.6节模型为新物理身份，与1.1~1.5节不做未标注的同分布比较。

辅助任务失效；该原因仍是单seed假设。

## 5. 当前原因假设排序

| 优先级 | 假设 | 置信度 | 主要支持证据 | 反证实验 |

## 6. 下一轮最低实验
