# 模型评估：auxiliary-action-rank-active-r3

## 1. 身份与证据

本报告同时记录排名主动学习 24M 父 run 与从其最终 checkpoint 续训到 34M 的结果。两者
均使用 `score_v1`、5 层 GNN、5 个 bootstrap 策略头、动作效果辅助监督和相同训练 seed
`20260809`。排名主动学习把价值名次与不确定性名次相加，从综合前 4 项均匀随机选择；
epsilon 为 0.05 时，主动学习、epsilon 随机和贪心分支分别为 40%、5%、55%。

`【事实】` 两个外层归档的本地 SHA-256 与云端校验文件完全一致；所有 manifest 项均为
完整文件精确哈希匹配，没有日志尾部追加差异。两组 `best.pt` 和 `final.pt` 均可在本地

`【事实】` 34M 是从 24M `final.pt` 恢复模型、target、Adam、RNG 和累计计数后的连续延长。
当前 checkpoint 不保存 Replay，续训前重新构造 262,144 条 Replay。第一次恢复暴露 CUDA
映射 RNG sidecar 的设备错误，在任何更新发生前失败；`c01cedb` 修复后才建立正式 34M run。

## 2. 已确认效果

最终评估均使用相同 seed base `42,000,000`，每种 FPS 各 4096 局。

| 指标 | 24M 30 FPS | 34M 30 FPS | 24M 120 FPS | 34M 120 FPS |
| --- | ---: | ---: | ---: | ---: |
| 局均分 | 4226.63 | **4493.78** | 3949.27 | **4183.56** |
| 中位分 | 3876 | **3996** | 3743 | **3865** |
| 标准差 | 1494.55 | 1682.74 | 1320.04 | 1495.34 |
| 局均投放 | 404.19 | **425.95** | 380.38 | **399.13** |
| 局均合成 | 376.92 | **399.93** | 353.32 | **373.44** |
| 平均最高等级 | 10.7583 | **10.7844** | 10.6777 | **10.7341** |
| 终局水果数 | 27.15 | **25.84** | 26.96 | **25.56** |
| 危险投放率 | 7.64% | **7.38%** | 8.21% | **8.13%** |
| settle timeout 率 | 0.096% | 0.117% | 0.123% | 0.135% |
| 产生 L11 的局数 | 3249 | **3365** | 2941 | **3162** |

`【事实】` 34M 相对自身 24M 父模型在 30/120 FPS 分别提高 267.15（+6.32%）和
234.29（+5.93%）；中位分、投放数、合成数、最高等级和 L11 覆盖均同向提高。30 FPS
L11 覆盖率从 79.32% 增至 82.15%，120 FPS 从 71.80% 增至 77.20%。这支持“24M 时当前
模型仍未完全收敛”的观察。

`【事实】` 低 epsilon 后期 20 个训练窗口中，24M / 34M 的主动分支均值为 39.94% /
40.10%，实际改变全部动作 33.14% / 33.20%，主动与贪心重叠约 17%，双排名相关系数均约
-0.27。三级分支与排名选择机制在续训前后保持稳定执行。

`【事实】` 34M 仍未超过辅助动作首轮 6.4M 配置：30/120 FPS 低 355.87（-7.34%）和
292.79（-6.54%）。相对 18M epsilon 模型，30 FPS 低 92.84（-2.02%），120 FPS 高
4.35（+0.10%）；相对 5 层 Fast 基线则高 225.64（+5.29%）和 286.27（+7.35%）。

`【决策】` 追加 10M 对本次排名主动学习模型有效，但不能据此把排名主动学习升级为当前
默认方案；辅助动作首轮 24M 仍是效果领先模型。34M 只能作为“训练预算延长有效”的证据，
不能单独证明增益来自排名主动分支。

## 3. 已确认不足

- `【事实】` 排名主动 24M 在 30/120 FPS 仅为 4226.63/3949.27，低于辅助动作首轮和
  18M epsilon 模型；相同 24M 预算下没有表现出更高的样本效率。
- `【事实】` 34M 虽明显恢复，但多消耗约 10M transition 后仍低于辅助动作首轮 24M；
  当前不能用更高训练成本换取默认方案升级。
- `【事实】` 30→120 FPS 分数由 4493.78 降至 4183.56，迁移损失约 6.90%；双帧率绝对
  分数均提高，但物理迁移问题没有消失。
- `【事实】` 续训不恢复 Replay，34M 的前 262,144 条经验为重新预热数据；这使它不是
  逐经验无缝延长，也不能和从零独立训练 34M 完全等同。

## 4. 原因假设

| 假设 | 置信度 | 支持证据 | 反对证据 | 反证或验证方式 |
| --- | --- | --- | --- | --- |
| 当前模型在 24M 尚未收敛，低 epsilon 继续训练能提高策略 | 中高 | 34M 双帧率、局长、合成和 L11 均高于父模型 | 只有一个续训 seed，且 Replay 重建 | 第二 seed 做相同 24→34M 延长，或从零训练 34M |
| 排名 Top-4 的高主动比例降低前 24M 样本效率 | 中 | 排名 24M 低于三个既有辅助模型中的两个，34M 才部分追回 | 配置与旧 bonus 方案不只主动选择不同 | 同 seed、同 24M，仅切换旧主动策略与排名策略 |
| 34M 增益主要来自普通低 epsilon 利用，而非不确定性主动学习 | 中 | 没有关闭主动分支的成对 run；贪心仍占 55% | 主动分支实际改变约 33% 的全部动作 | 以相同 checkpoint 做 10M 续训，主动概率 40% 对 0% |
| Replay 重建造成暂时扰动但不决定最终结果 | 中低 | 10M 预算足以覆盖 1M Replay 容量多次 | 没有保存重建前后固定评估 | 增加可选 Replay checkpoint，做精确恢复对照 |

## 5. 下一轮最低实验

1. `【方案一｜推荐】` 暂停继续增加本 run 预算，先用固定 24M checkpoint 做一对 10M
   续训：排名主动 40% 对主动关闭 0%，其余配置和 Replay 重建完全相同，直接估计主动分支
   在后期的净贡献。
2. `【方案二】` 若优先验证跨 seed 稳定性，复现第二个训练 seed 的 24M 排名主动 run；
   只有同样出现 24M 偏低、34M 回升，才能把样本效率判断升级为稳定结论。
3. `【方案三｜暂不推荐】` 继续把单个 run 延长到 44M。它只能继续描绘单 seed 学习曲线，
   不能区分排名主动学习、普通利用和 Replay 重建的贡献。

## 6. 证据边界

- 训练只有一个 seed；4096 局评估能压低评估采样误差，但不能估计训练随机性方差。
- 24→34M 同 checkpoint 比较同时改变训练预算和经历一次 Replay 重建，属于预算延长证据，
  不是主动学习消融。
- 报告没有新增人工场景观察；所有行为结论仅来自结构化指标、双帧率评估和事件索引。
- 归档、checkpoint 和清单已完整迁回本地，但大体积 `runs/` 产物不提交 Git。
