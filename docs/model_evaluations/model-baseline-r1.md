## 2. 已确认效果

- `【事实】` 30 FPS 周期评估从 4.00M 的 2793.43 提高到最终 3280.29；训练确实获得了可测提升。
- `【事实】` 120 FPS 局均分比30 FPS低6.92%，存在可复现的训练/评估物理帧率差异。
- `【事实】` 最后20个训练窗口平均约6197 env steps/s、3.462 updates/s，GPU利用率约98.5%。
- `【决策】` 在出现可靠更优模型前，本模型作为真实游戏效果和训练吞吐的基准参考。

## 3. 已确认不足

1. 训练没有完成冻结的16M transition，只完成90.51%；后续严格比较应统一实际训练量。
2. 30→120 FPS 有约6.92%的分数下降，30 FPS策略对更精细物理并非完全稳健。
3. 评估标准差约739，单个短评估窗口不足以判断小幅改进。
4. 两侧动作合计占29.36%，明显高于21动作均匀策略的9.52%；这可能是有效边缘策略，也可能是动作偏置，当前证据不能定性。
5. 模型只有一步 TD 奖励和局部物理图，没有显式合成链、长期计划、可联通性或动作效果辅助监督。

## 4. 原因假设

| 假设 | 置信度 | 支持证据 | 反证或验证方式 |
| --- | --- | --- | --- |
| 30/120差异主要来自30 FPS训练物理的分布偏移 | 中高 | 相同模型和评估种子仅改变物理帧率即下降6.92% | 用混合物理微调或帧率随机化后复评 |
| 边缘动作偏好是保持中央空间的有效策略 | 低 | 两端动作频率高，模型得分仍明显优于 Reward V2 | 固定对称场景比较边缘/内部动作的长期回报 |
| 一步分数奖励使模型擅长即时合成但缺少长期链规划 | 中 | 模型设计没有长期监督；仅凭最终分数不能直接证明 | 保存长轨迹并按高等级合成前16/64步分析动作质量 |

## 5. 下一代比较要求

- 保持相同模型主体时，奖励消融必须至少达到本报告的30/120 FPS分数基准；
- 最终评估建议不少于1024局并使用 seed base 32,000,000；
- 记录动作位置分布、终局等级计数和同级水果积压，而不只记录总分；
- 增加固定场景集，验证边缘偏好、缝隙处理和合成链选择。

## 6. 证据边界

本报告只有一个训练 seed。训练分数、TD loss 和 shaped reward 不用于宣称跨模型优越性；
所有跨代结论以独立 greedy 评估为主。原始 run 属于本地/外部产物，不保证在 Git 克隆后存在。
