- `【事实】` 30 FPS周期评估从2.10M的2120.80提高到12.58M的2603.93，空间奖励能够驱动学习。
- `【事实】` 相对基线，最终30 FPS局均分低23.00%，120 FPS低24.36%；退化远大于评估采样误差。

- `【事实】` 相同1792环境、batch和种子的成对热路径基准中，空间奖励吞吐是分数奖励的99.47%，净开销约0.53%。
- `【决策】` 当前版本只保留为失败但有价值的奖励实验，不作为新的效果基线。

## 3. 已确认不足

1. 纯空间奖励没有提高真实游戏表现，且在30/120 FPS均明显落后于分数基线。
2. 奖励分布严重偏正；最终窗口只有约1.97%的样本为负，可能缺少区分不合理投放的有效梯度。
3. 合成更少、终局水果更多，说明可投放空间代理没有自动转化为更好的合成清理能力。
4. 当前21列几何只计算静态垂直路径，不表达同级对齐、横向可联通性、未来移动趋势或合成链价值。
5. 实际只完成83.67%的目标 transition；虽然不足以解释约23%的全部差距，但削弱了严格因果比较。
6. 场景实验室的人工作用结果没有保存为固定场景集，无法量化哪些局面最容易被空间奖励误判。

## 4. 原因假设

| 假设 | 置信度 | 支持证据 | 反证或验证方式 |
| --- | --- | --- | --- |
| 空场平均补偿在拥挤状态中过度补偿，令多数动作得到正奖励 | 中高 | 最终补偿均值约为原始损失绝对值的6.5倍，正奖励率98.03% | 按场面密度和动作记录分位数；比较无补偿与条件补偿 |
| 奖励把“与既有阻挡重叠占用”视为高效空间利用，却没有要求同级水果真正可合成 | 中高 | 终局水果更多、合成更少；补偿与动作无关 | 构造空间面积近似但同级对齐不同的成对场景 |
| 静态垂直走廊遗漏横向运动、阻挡解除和合成链，代理目标与长期得分错位 | 中高 | 当前设计明确排除动态可达性；最高等级与合成数均下降 | 引入只读对齐/可联通诊断，先做离线相关性分析 |
| 训练量少7.56%是主要退化原因 | 低 | Reward V2实际transition更少 | 把 Reward V2 延长到相同transition；若仍低约20%则反证 |
| Reward V2计算太慢导致学差 | 低 | 成对热路径净开销只有0.53% | 用完全相同评估频率的成对长训复核完整吞吐 |

## 5. 下一轮最低实验

1. 在不改模型的情况下先完善奖励分布日志，输出 raw delta、compensation 和 reward 的分位数及分层统计；
2. 固定一组覆盖空场、中局、拥挤、同级对齐、底部缝隙和临界出界的场景；
3. 对每个固定场景保存21动作的空间奖励、模型Q值和真实短期合成结果；
4. 只改一项补偿语义，使用相同训练量与评估计划做 `score_v1` / 当前 V2 / 修正版三组消融；
5. 修正版若仍不能在真实分数、合成数和终局水果数上接近基线，不进入更复杂模型训练。

## 6. 证据边界

补偿过强和代理目标错位目前是解释本次结果的高优先级假设，不是已完成的因果证明。
原始 run 只有一个训练 seed，且与基线的实际训练量和评估频率不同。Reward 数值只能在
本模型内部解释，不能与 `score_v1` 的 mean reward 横向比较。
