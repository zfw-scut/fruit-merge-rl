- `【事实】` Fast相对Slow的30 FPS均值提高171.83（+4.19%），相同4096个评估seed的
  成对95%区间为`[108.33, 235.33]`；120 FPS提高109.87（+2.90%），区间为
  `[55.88, 163.87]`。评估采样误差不足以解释差异。
- `【事实】` Fast在30/120 FPS分别有53.25%/53.25%的同seed对局得分高于Slow；分差
  中位数分别为72.5和73.5。Fast改善了整体分布，但不是每个初始seed都占优。
- `【事实】` Fast的30→120 FPS均值下降8.69%，Slow下降7.54%。Slow略抗帧率变化，
  但120 FPS绝对分仍低Fast 109.87。
- `【事实】` Fast最外侧动作比Slow多3.74个百分点。墙边投放是常见策略，只将其记录为
  行为差异；现有证据不能把Fast增益或物理迁移损失归因于墙边动作。
- `【决策】` 在当前单seed证据下，Fast替代Slow并成为新的简洁`score_v1`效果基准；
  不采用Slow作为后续默认epsilon。

## 3. 高分尾部与L11关键事件

| 30 FPS，4096局 | Fast | Slow | Fast-Slow |
| --- | ---: | ---: | ---: |
| 5000+ | 574 / 14.01% | 446 / 10.89% | +3.12个百分点 |
| 7000+ | 428 / 10.45% | 340 / 8.30% | +2.15个百分点 |
| 10000+ | 50 / 1.22% | 33 / 0.81% | +0.42个百分点 |
| 生成过L11 | 3215 / 78.49% | 3159 / 77.12% | +1.37个百分点 |
| L11作为源水果再次合成 / 消除 | 531 / 12.96% | 416 / 10.16% | +2.81个百分点 |
| 发生L11消除后的局均分 | 7824.17 | 7772.51 | +51.66 |

- `【事实】` 两组30 FPS全部7000+和10000+对局都发生了L11消除；120 FPS也完全相同。
  高分尾部不是普通局长噪声，而与最高等级关键合成事件直接绑定。
- `【事实】` 单纯生成L11的比例高达77%～78%，但7000+只有8%～10%；“生成大西瓜”
  本身不足以产生高分，能否继续完成L11消除才是更强的分层标签。
- `【事实】` 两组发生L11消除后的条件均分只差51.66，而Fast让该事件多发生115局。
  Fast的高分优势主要来自更频繁进入关键事件，而不是事件发生后单局得分明显更高。
- `【决策】` 后续反事实归因应优先围绕“首次L11消除前16/64步的铺垫”和“已生成L11
  但最终未消除”的配对轨迹，而不是笼统地重放所有高分局。

## 4. 学习曲线与epsilon结论

Slow在2.10M～10.49M的周期评估领先Fast约20～122分；Fast在12.58M首次反超，并在
16.78M以后持续领先。最后三个512局30 FPS周期评估为：

| transition | Fast | Slow |
| --- | ---: | ---: |
| 18.88M | **4285.56** | 4029.02 |
| 20.97M | **4200.74** | 4098.73 |
| 23.07M | **4222.33** | 4055.96 |

- `【事实】` 延长高epsilon提高了前期探索期评估，但没有在相同24M预算下得到更高的最终
  greedy上限；Fast在中后段反超并保持到4096局最终评估。
- `【事实】` 1M后训练吞吐中位数为Fast 4589.43/s、Slow 4391.36/s。两组模型计算量
  完全相同，差异还包含探索策略导致的局长和场景复杂度变化，不能写成epsilon本身的固定
  性能开销。
- `【假设】` Slow长期保留更多随机动作，推迟了对已发现L11消除轨迹的稳定利用。置信度
  中等；支持证据是反超时点和最终关键事件频率，反证需要第二个训练seed。
- `【决策】` 当前不再继续放慢epsilon。若后续需要更多探索，应优先考虑关键事件Replay、
  不确定性驱动探索或阶段性再升温，而不是全局延长随机动作。

## 5. 相对既有基准

| 模型 | 参数 / 层数 | transition | 30 FPS均分 | 120 FPS均分 |
| --- | ---: | ---: | ---: | ---: |
| 3层`baseline-r1` | 725,423 / 3 | 14.481M | 3280.29 | 3053.43 |
| 4层`baseline-scale-v1-l4-r1` | 876,734 / 4 | 16.001M | 3742.69 | 3471.08 |
| 5层Fast | 1,028,045 / 5 | 24.001M | **4268.14** | **3897.29** |
| 5层Slow | 1,028,045 / 5 | 24.001M | 4096.31 | 3787.42 |

- `【事实】` Fast相对4层在30/120 FPS提高525.45（+14.04%）/426.21（+12.28%）；
  独立样本近似95%区间分别为`[466.97, 583.93]`和`[376.63, 475.79]`。
- `【事实】` Slow相对4层也提高9.45%/9.11%。两种epsilon的5层完整配置都明显超过
  4层当前基准。
- `【事实】` 5层相对4层参数量增加17.26%，训练量增加50.0%，同时环境数、batch、
  seed和评估seed base也不同。因此不能把约9%～14%的全部提升写成“增加一层消息传播”
  的单因素净收益。
- `【决策】` 当前确认的是“5层Fast完整训练配置整体最优”。若未来必须量化第五层的净
  收益，应补同24M、同batch、同epsilon的4层对照；在云成本优先时可暂不补跑。

## 7. 建议与证据边界

- `【建议一】` 后续模型升级以5层Fast为默认对照，保持4096局30/120 FPS和L11关键事件
  统计，不再只比较均分或窗口最高分；
- `【建议二】` 下一项长期归因实验使用现有紧凑索引筛选“L11已生成但未消除”和“成功
  消除”配对局，仅对候选局回放16/64步，避免恢复旧分支的全在线重型归因；
- `【建议三】` 在下一轮云端训练前修复manifest顺序，让`training_finished`和最终资源
  采样先落盘，再生成内部清单；
- `【建议四】` 若要把Fast对Slow的结论升级为跨训练随机性结论，至少补一个训练seed；
  当前4096局区间只消除了评估采样误差，不能覆盖训练seed方差。

Fast/Slow使用相同训练seed和评估seed，但最终同seed分数相关系数仅约0.02，说明不同策略
会迅速产生不同物理轨迹。成对区间仍是有效的同初始seed比较，但几乎没有获得额外方差缩减。
