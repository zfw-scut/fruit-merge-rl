# 模型评估：当前几何堵塞检测器

## 1. 身份与任务语义

| 项目 | 内容 |
| --- | --- |
| 短称 / 正式ID | `PB-GEO` / `pair-blockage-geometry-50k-r1` |
| 代码身份 | `main@6ae0f39f5ecd615cd4de6b124b9414b5c4804725` |
| 模型 | 7,345参数，Geometry Pair-conditioned Deep Sets |
| 输入 | 当前位置、物理半径、等级、有效掩码、目标水果对 |
| 输出 | `p_blocked_now`单logit；当前堵塞排序分数 |

| 训练 | RTX 5090，batch 65,536，BF16，24轮，seed 20260824 |

`confirmation_drops=24`只用于验证回溯起点和排除未知尾部，不限定正例长度。

指标用于评价事件覆盖，不是逐投放边界精度。

## 3. 证据判断

`【事实】` L7～L11各等级AP都显著高于该等级自然正例率，纯当前几何足以提供可学习的
堵塞排序信号；L9～L11明显强于L7/L8。

`【事实】` 模型只有7,345参数；65,536 batch短测为459,174样本/秒，峰值CUDA保留约
5.2GB。正式24轮训练耗时133.74秒，训练吞吐不是当前主要工程瓶颈。

`【边界】` 等级×标签平衡改变了训练先验，sigmoid值尚未校准。尤其L7在0.5阈值下
precision只有0.1025，因此不能把统一阈值输出直接作为行为段边界或“真实概率”。

`【边界】` 当前只有一个训练seed，且标签事实仍由人工阈值的长期停滞检测器定义；本次
结果证明代理能拟合该定义，不证明它捕获了全部游戏语义上的堵塞，更不证明策略收益。

## 4. 决策与下一验证

- `【决策】` 保留`PB-GEO`作为当前时刻堵塞代理基线，旧未来24投放风险模型继续作为
  不同语义的历史对照，二者不可互换；
- `【决策】` 暂不输入Policy，也不作为反事实最终因果判断；
- `【事实】` 当前语义的冻结测试集TP/FP/FN/TN场景画廊已经按L7～L11生成并迁回本地；
- `【建议】` 下一步结合画廊人工检查L7/L8误报与事件起点附近的迟检，再在冻结验证集
  选择逐等级阈值或做简单校准；
- `【反证条件】` 若逐等级校准后L7/L8仍无法在可接受误报下保持事件召回，或画廊显示
  模型主要利用等级/高度而非阻隔结构，则应升级几何编码，而不是直接接入反事实管线。
