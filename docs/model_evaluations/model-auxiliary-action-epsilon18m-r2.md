## 3. bonus影子量纲与实际主动学习强度

18M以后各统计窗口中位数：

| bonus | 影子动作改变率 | 改变动作Q代价 | 不确定性增益 |
| ---: | ---: | ---: | ---: |
| 0.5 | 6.81% | 0.000797 | 0.003209 |
| 1 | 13.02% | 0.001632 | 0.003313 |
| 2 | 23.57% | 0.003447 | 0.003533 |
| 4 | 38.79% | 0.007277 | 0.003890 |
| 8 | 55.60% | 0.014860 | 0.004384 |

- `【事实】` bonus增大时动作改变率单调增加，影子统计具有足够分辨率，没有发生所有档位
  近乎重合的问题。
- `【事实】` bonus=1在所有动作上的影子改变率中位约13.02%；结合只占epsilon动作75%的
  主动mask，18M后实际动作被主动学习真正改变的比例中位仅0.487%。
- `【事实】` 因此“主动学习动作率约3.75%”只是进入主动分支的mask比例，不代表3.75%的
  行为偏离贪心策略。绝大多数bonus=1候选仍与mean-Q贪心动作重叠。
- `【观察】` bonus=2把改变率提高到约23.6%，且条件Q代价与不确定性增益量级接近；这说明
  bonus=1确实偏保守，但不能仅凭影子改变率确定bonus=2会提高得分。
- `【事实】` 18M后的主动mask中位为3.766%。若保持同一mask并以影子重叠率估算，
  bonus 0.5/1/2/4/8真正改变全部动作的比例约为0.26%/0.49%/0.89%/1.46%/2.09%；
  bonus=1的估计值与实际记录0.487%一致。
- `【事实】` 后期Q动作范围中位0.1318、Top1/Top2间隔0.00655、策略头分歧0.00728、
  最大不确定性0.01295。bonus=1发生动作改变时，Q代价0.00163、不确定性增益0.00331；
  量纲并非小到完全无法改变动作，而是改变候选只覆盖约13%。
- `【事实】` 各bonus条件下的`beta × 不确定性增益 / Q代价`约为2.01～2.36。该比值是
  argmax筛选后的条件统计，只说明被选中动作的bonus收益足以覆盖Q代价，不能当作bonus已
  校准到最优的证据。
- `【决策】` 下一轮若调整主动学习，优先对bonus=1与2做行为对照；不直接采用4或8，因为
  它们分别改变约39%和56%的候选动作，策略扰动明显更大。正式实现前仍需结合时间分位数和
  关键事件条件统计。

## 4. 训练性能与结论边界

`【事实】` 本轮1M以后端到端吞吐中位约3075.99 transition/s，低于首轮3486.53/s。
影子计算不增加模型前向或Replay数据，但增加五档逐动作运算与监控字段；该吞吐差异同时
可能受云服务器状态影响，不能直接全部归因于影子计算。

| 21.6M后训练诊断中位数 | 首轮6.4M | 本轮18M |
| --- | ---: | ---: |
| DQN loss | 0.02798 | 0.02803 |
| 辅助总loss | 0.12656 | 0.12534 |
| 合成组 | 0.26250 | 0.25809 |
| q0谱系组 | 0.19313 | 0.19207 |
| 首次接触组 | 0.06599 | 0.06916 |
| 新水果组 | 0.09891 | 0.09722 |
| 结果组 | 0.01031 | 0.01029 |
| 策略头分歧 | 0.02081 | 0.02029 |
| bootstrap有效率 | 0.80016 | 0.80026 |

`【事实】` 两轮后期DQN loss、辅助总loss、五个辅助分组、策略头分歧和bootstrap有效率
都非常接近。18M版本的效果下降不能由“辅助监督没有收敛”或“策略头塌缩”直接解释。

`【事实】` 本轮30 FPS最外侧动作占31.51%，低于首轮35.20%和Fast的46.41%，但分数
仍低于首轮；这再次说明不能把墙边动作占比单独当作策略质量指标。L9/L10/L11每千次投放
生成密度为20.098/8.323/2.776，位于Fast的19.708/8.018/2.599与首轮辅助模型的
20.403/8.694/2.951之间，与最终效果排序一致。

`【观察】` 23M附近的512局周期评估一度让18M版本高于首轮，但最终4096局结果反向且差异
明确。周期评估适合观察趋势，不足以用单个点选择模型。

`【假设】` 在固定24M预算下，延长高epsilon随机动作占比减少了后期利用当前策略收集高价值
长链经验的时间，因而降低高分尾部和L11事件进入率。置信度中等；支持证据是同seed双帧率
与高等级事件同向下降，反证实验是第二训练seed下18M不再落后，或增加总训练预算后18M追平。

`【决策】` 下一步先分析本轮已保存的bonus影子时间序列与关键事件轨迹，再决定是否训练
bonus=2对照；不再继续延长epsilon下降时间，也不同时修改辅助loss权重。

## 5. 后续方案

1. `【方案一｜推荐】` 恢复首轮6.4M epsilon日程，只把实际主动学习bonus从1提升到2，
   保持训练seed、模型、辅助loss和24M预算不变。影子数据预计有效改变全部动作约0.89%，
   比bonus=1约翻倍但仍远低于epsilon总预算，最适合做下一项单变量对照。
2. `【方案二｜保守】` 暂不长训，先按“是否进入L10/L11事件”和动作位置分层分析现有
   transition样本中的bonus=1/2影子分歧；成本低，但只能筛选风险，不能替代在线行为验证。
3. `【方案三｜暂不推荐】` 直接使用bonus=4或8。两者会改变约39%/56%的主动候选，预计
   影响全部动作约1.46%/2.09%，相对bonus=1跨度过大，不适合作为第一步校准。
