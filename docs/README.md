## 当前事实

- 合成水果创建瞬间线速度和角速度为零。
- 训练、评估和场景实验室共用 `TensorVectorSimulator` 与同一 CUDA Kernel；Pymunk 已退出当前运行依赖。
- 自由落体快进已从 Python/Tensor 与 CUDA 执行路径删除；训练、评估和场景实验室均逐帧模拟投放后的完整下落过程。
- 当前稳定判定使用完整物理帧求解前后的圆心位移，并保留角速度条件；物理身份为
  `tensor_cuda_v4_solved_motion_stability`。
- 已实现独立的L7～L11同级水果对长期停滞检测器：L9～L11按长期净位移停滞判断，
  L7～L8额外要求持续相邻；检测只服务真实rollout离线标签和未来反事实验证，尚未训练
  单帧风险网络，也不进入Policy、Replay或当前正式训练。
- 旧配置中的 `drop_fast_forward` 仅为读取兼容保留，传入 `true` 也会归一化为 `false`；旧物理身份的 checkpoint 不允许直接恢复训练，只能 weights-only 迁移。
- 正式训练默认不设置单局投放次数上限，并记录长局规模与水果槽占用；当前不按局长刷新或
  降权。固定64水果状态容量属于独立技术边界，命中时终止该局并单独累计监控。
- 场景实验室提供“Tensor/CPU vs CUDA后端”和“当前游玩 vs 当前训练配置”双环境实时对照。
- 场景实验室提供完整加权 Voronoi 空间图参考可视化；该图尚未接入 observation、Replay
  或 Q 网络，不代表当前模型已使用 Space Graph。
- Fruit Graph 的现行物理边增加了“配对最低结果圆”：中心按标准半径比例偏向较小水果，
  半径取较高等级再升一级后的合成物理半径；L11 相关配对显式表示为无结果圆。该输入
  已完成 CPU 几何验证，但尚未训练或评估，不能据此声称策略效果提升。
- 旧 14 维物理边 checkpoint 可通过新增列补零继续用于查看或 weights-only 初始化；
  SAB-128 终局画廊支持 CPU 逐局诊断，CPU 模式不使用 CUDA 掩码步进。
- 已建立计划中的`SAB-FF30-E18`从零训练配置：128M父轨迹、16,777,216条单步旁路、
  完整辅助任务和当前18维边。SAB-128仅作为最多300投放的预热teacher，不初始化新模型
  权重；云端CUDA预检和5档真实短跑标定已完成，64水果表示容量的Replay预热门禁已经
  修复并通过，128M正式训练正在6号实例运行。
- 新吞吐工具直接运行正式`BaselineTrainer`短跑，自动覆盖父训练与旁路联合训练阶段，并在
  最多约4个环境候选和1个额外batch候选中给出推荐；旧合成benchmark不再用于本轮选型。
- `SAB-128`在当前无快进环境中的 Merge Potential 20,000局正式采集和离线标签汇总已
  完成，全部为自然终局，正式数据已迁回本地；门户已提供时间尺度、单因素、双因素与原始
  表格分析页，Merge Potential辅助任务尚未生成。
- 门户统一承载文档、工具、统计分析、训练遥测和场景实验室。
- 最新归档模型为完整逐帧120 FPS下的16M无旁路对照及从精确8M checkpoint分叉的2.097M旁路续训模型；最终结果不升级旁路版。
