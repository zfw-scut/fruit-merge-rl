## 当前事实

- 合成水果创建瞬间线速度和角速度为零。
- 训练、评估和场景实验室共用 `TensorVectorSimulator` 与同一 CUDA Kernel；Pymunk 已退出当前运行依赖。
- 自由落体快进已从 Python/Tensor 与 CUDA 执行路径删除；训练、评估和场景实验室均逐帧模拟投放后的完整下落过程。
- 当前稳定判定使用完整物理帧求解前后的圆心位移，并保留角速度条件；物理身份为
  `tensor_cuda_v4_solved_motion_stability`。
- 已实现独立的L7～L11同级水果对长期停滞检测器：L9～L11按长期净位移停滞判断，
  L7～L8额外要求持续相邻；检测只服务真实rollout离线标签和未来反事实验证，不进入
  Policy、Replay或当前正式训练。
- 已实现由SAB-128真实对局和上述检测器生成监督数据的独立工具，以及不构图、不读取瞬时
  速度/角速度的Pair-conditioned Deep Sets轻量风险模型与训练评估入口；2,000～6,000环境
  标定选择5,000环境，正式采集得到50,174个确认事件和1,714,133条有效标签。独立测试的
  逐等级宏平均AP为0.6905，L9～L11排序能力较强，但统一0.5阈值下L7/L8仍有明显误报；
  测试集画廊已升级为“预测帧—堵塞起点—确认帧”的时间序列验证，并按四档预警距离拆分。
  该模型已作为只读诊断层接入场景实验室：稳定场景下用CPU批量显示L7～L11同级水果对
  在未来24次投放内的堵塞起始风险；仍未接入Policy、Replay或反事实旁路。
- 在保留上述未来风险模型的同时，新增语义独立的当前几何堵塞检测器：复用原始确认事件，
  将完整`onset～end`存续区间标为正例；模型只读取水果位置、物理半径、等级、有效掩码和
  目标对，不读取年龄、队列、危险线、运动量或预合成结果圆。其checkpoint与旧模型互不
  兼容，当前仅进行独立监督训练，不进入Policy、Replay或反事实最终判断。
- 当前几何堵塞检测器`PB-GEO`已在2,080,153条确定标签上完成正式训练；独立测试逐等级
  宏AP为0.7139，L7～L11 AP依次为0.4261/0.5098/0.7837/0.9063/0.9434。统一0.5阈值
  尚未按自然先验校准，尤其L7误报较多；当前输出只作为堵塞排序分数，不直接划分行为段。
  正式测试集已生成按L7～L11与TP/FP/FN/TN分组的当前语义人工画廊；TP/FN同时显示
  起点前记录、经后续轨迹确认的起点和当前分类记录，但各帧分数都只表示当前是否堵塞，
  不再使用旧的“未来多久到堵塞起点”预测语义。
- 后续因果审查已停止把未来风险模型或`PB-GEO`作为反事实行为段的主边界生成器：堵塞
  显现点常由近期碰撞触发，但真正形成难恢复结构的投放可能早得多。长期检测器、监督数据、
  冻结模型和画廊继续作为离线失败检索、分支结果验证和研究对照保留；完整演化与弃用原因见
  `development_tracks/01_pair_risk_to_blockage/`。
- 旧配置中的 `drop_fast_forward` 仅为读取兼容保留，传入 `true` 也会归一化为 `false`；旧物理身份的 checkpoint 不允许直接恢复训练，只能 weights-only 迁移。
- 正式训练默认不设置单局投放次数上限，并记录长局规模与水果槽占用；当前不按局长刷新或
  降权。固定64水果状态容量属于独立技术边界，命中时终止该局并单独累计监控。
- 场景实验室提供“Tensor/CPU vs CUDA后端”和“当前游玩 vs 当前训练配置”双环境实时对照。
- 场景实验室提供完整加权 Voronoi 空间图参考可视化；该图尚未接入 observation、Replay
  或 Q 网络，不代表当前模型已使用 Space Graph。
- Fruit Graph 的现行物理边增加了“配对最低结果圆”：中心按标准半径比例偏向较小水果，
  半径取较高等级再升一级后的合成物理半径；L11 相关配对显式表示为无结果圆。该输入
  已完成 CPU 几何验证，但尚未训练或评估，不能据此声称策略效果提升。
- 旧 14 维物理边 checkpoint 可通过新增列补零继续用于查看或 weights-only 初始化；
  SAB-128 终局画廊支持 CPU 逐局诊断，CPU 模式不使用 CUDA 掩码步进。
- `SAB-FF30-E18`已从零完成128.001280M父轨迹和16,777,216条单步旁路训练，SAB-128
  只作为最多300投放的预热teacher；最终4096局30 FPS均分/中位分为6688.94/5123.5。
  三份关键权重、评估索引、完整日志、曲线、身份和配置已迁回本地并逐文件校验；该结果是
  当前完整逐帧18维边的新基线。同V4物理下SAB-128补零复评均分为6430.51，新基线同seed
  高258.43分且成对95%区间为`[+134.57,+380.87]`；结果仍不能拆成取消快进或新增边属性
  的单项增益。
- 新吞吐工具直接运行正式`BaselineTrainer`短跑，自动覆盖父训练与旁路联合训练阶段，并在
  最多约4个环境候选和1个额外batch候选中给出推荐；旧合成benchmark不再用于本轮选型。
- `SAB-128`在当前无快进环境中的 Merge Potential 20,000局正式采集和离线标签汇总已
  完成，全部为自然终局，正式数据已迁回本地；门户已提供时间尺度、单因素、双因素与原始
  表格分析页，Merge Potential辅助任务尚未生成。
- 门户统一承载文档、工具、统计分析、训练遥测和场景实验室；训练页已支持多实例来源与
  通用任务快照，另提供不启动物理/模型服务的轻量JSON场景查看页。
- 最新归档模型为完整逐帧120 FPS下的16M无旁路对照及从精确8M checkpoint分叉的2.097M旁路续训模型；最终结果不升级旁路版。
- Android游戏已合并到当前分支并接入无旁路`SAB-FF120 final.pt`；其Java物理不再包含逐水果运动学休眠。
