# 01｜从风险预测器到堵塞检测器

## 先说结论

这段工作解决了一个问题，也暴露了另一个更根本的问题。

我们已经能够用真实后续轨迹定义L7～L11同级水果对的长期停滞事件，也训练出了轻量的
未来风险预测器和当前几何堵塞检测器。尤其对L9～L11，单帧几何确实包含相当强的可学习
信号。问题在于：**堵塞被看见的时刻，经常不是应该承担因果责任的投放时刻。**

因此，本阶段最终放弃的是“把堵塞代理直接当作反事实行为段主边界”这一职责，而不是删除
检测器、模型、数据或画廊。它们仍然适合做离线失败检索、分支结果验证和后续研究对照。

状态：**主路线弃用，诊断资产保留。**

## 这段经历覆盖什么

时间范围主要是2026-08-23至2026-08-25，包含：

1. 用多投放窗口定义同级高等级水果对长期停滞；
2. 把昂贵的轨迹事实压缩成轻量单帧“未来风险”代理；
3. 发现预测语义不等于当前堵塞，重新训练纯几何的当前检测器；
4. 用时间序列画廊检查模型究竟在判断什么；
5. 发现堵塞显现时间与真正可归因的决策时间错位，停止把它作为行为段主边界。

“可合成性”只是这段工作结束后出现的候选方向，本目录不会提前替它写实现规格。
