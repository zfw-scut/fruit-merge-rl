# 当前方案规格协作规则

- 先读本目录 `README.md`，再读目标模块自己的 `README.md`；不要预先通读全部子方案。
- `design_specs/` 描述当前准备怎样实现，属于可修订的生效规格；历史复盘去
  `../development_tracks/`，实际修改事实去 `../codex/`。
- 实现前先把对应子方案更新为“已选择待实现”；收到观察反馈后，先修订子方案及状态，再
  切换代码实现。
- “暂定采用”表示可以支持第一版开发，但仍需要通过人工观察或实验决定是否保留；不得写成
  已验证结论。
- 文档保持算法级清晰，不复制代码变量、命令和大段实现细节；边缘情况、性能边界和容易误解
  的语义必须提前写明。
