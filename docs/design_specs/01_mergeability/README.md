# 01｜单水果可合成性

## 当前结论

本模块准备为稳定场景中的每颗水果计算一个连续的“可合成性”分数，表示它在未来参与下一次
合成的容易程度。分数同时考虑局部已有材料形成的内部升级路径，以及顶部继续输入材料形成的
外部供给路径。

当前不使用堵塞检测器，不把“长期不动”或“已经堵塞”作为计算前提。可合成性希望直接描述
结构还保留了多少合成机会，并在后续用于行为段划分和反事实候选分支评价。

状态：**原始分数与第一版空间结构分数均已实现；本地CUDA自然分布复算完成，尚未接入训练。**

## 已确认的方案

- 计算单位是单颗水果，输出连续的原始可合成性。
- 原始可合成性只描述合成容易程度；水果等级、位置等训练重要性另外加权。
- 总机会由内部升级路径和外部供给路径共同决定。
- 第一版使用目标水果的轻微膨胀圆建立定性局部邻域，不混入连续距离权重。
- 内部传播只保留少量最可能的定向依赖，不在所有邻居之间无限传播。
- 等级传递难度保持简单，主要由等级差表达，不混合速度、距离等不同量纲。
- 行为段节点和重大变化阈值等待可视化观察后再设计。
- 可合成性将承担行为段划分和反事实候选分支评价的重要角色。
- 原始可合成性继续描述材料、升级链和空间的综合机会；空间结构分数作为并列诊断量，不覆盖
  原始分数。
- 空间结构变化必须按投放前已有材料追踪合成谱系，不能再用水果圆面积和前后ID集合直接求差。

## 暂定采用但尚未验证

- 邻域先使用目标半径 `1.05R` 的膨胀圆；比例后续通过场景观察调整。
- 内部路径先计算离散难度，再映射成连续分数，避免递归减分产生无界负值。
- 同级邻居作为直接终点，低级邻居才继续向下递推，从而避免同级循环依赖。
- 多条路径暂时只取最容易的一条，不累加为资源总量。
- 单颗水果独立评估时允许不同目标暂时共享同一候选资源；第一版不求解全局资源竞争。
- 外部供给先拆成“空间容量”和“材料生成成本”，优先尝试轻量的顶部连通/通路容量判断；
  局部加权 Voronoi 作为简单方法不足时的候选升级。

## 第一代实现选择

- Top-K 暂取 3；
- 外部空间使用目标中心附近 5 条固定垂直探针，取其中最大可通过半径；
- 通路容量同时受墙体、目标上方水果和目标与投放线之间的纵向空间限制；
- 外部可直接输入等级不超过当前游戏的最高可投放等级 L5；
- 等级差的资源成本按最低二叉合成数量近似，最终通过可配置尺度映射为连续分数；
- 所有选择均封装在计算器配置和外部供给策略中，不作为长期冻结结论。

## 当前实现入口

- 固定张量计算器：`src/daxigua/rl/mergeability.py`；
- CPU/CUDA一致性与语义测试：`tests/test_mergeability.py`；
- 纯计算吞吐入口：`tools/benchmark_mergeability.py`；
- SAB-128真实对局画廊：`tools/visualize_mergeability_gallery.py`。
- 策略/随机混合复杂场景采集：`tools/collect_complex_scene_dataset.py`；默认在CUDA上同时
  生成2000个环境，运行到300次投放或自然终局，并保存可重复计算的完整稳定状态。
- 画廊工具可以直接读取上述静态场景数据集；更换可合成性子方案时无需重新运行物理对局，
  只需要针对同一批状态重新计算和绘图。
- 长期变化量采集：`tools/collect_mergeability_rollout_stats.py`；以SAB-128 greedy持续运行
  CUDA环境，逐投放分片记录`Σ(分数×πr²)`及同局差值，终局自动重置但不跨局做差。
- 离线统计绘图：`tools/analyze_mergeability_rollout_stats.py`；从原始分片生成变化量分位数、
  正负尾部、局内阶段和状态关系图。正式分布已完成，阈值仍未写入检测器。
- 负变化场景回查：正式分布与首版256组“投放前/稳定后”分层画廊方案见
  `08_长期变化分布与场景回查.md`；`tools/collect_mergeability_negative_transitions.py`
  负责CUDA分层蓄水池采集，`tools/render_mergeability_negative_gallery.py`负责CPU渲染，
  两者通过可复用快照数据集解耦。
- 空间结构统计：`09_空间结构分数与合成守恒.md`记录材料/空间拆分、守恒权重和谱系对齐；
  `tools/analyze_mergeability_structural_transitions.py`可以直接复算已有成对快照，长期采集器
  已同步记录合成次数和合成得分。

计算器目前只接受稳定场景状态并返回诊断表，没有修改observation、Replay、Policy、奖励或
反事实训练入口。外部供给通过独立策略接口注入，可以在不修改内部递推和调用方的情况下替换。

## 尚未讨论清楚

- 等级传递难度各档的具体大小，以及连续分数的映射方式；
- Top-K 的具体 K 值和同等级候选的稳定排序规则；
- 顶部到目标邻域的空间容量怎样轻量、稳定地计算；
- 可直接投放等级与内部生成链的准确供给成本；
- 最高等级水果是否纳入以及如何解释其“参与下一次合成”；
- 可合成性变化成为关键节点时的幅度、持续性和等级加权；
- 第一版是否只作为诊断层，还是同时产生离线辅助监督。

## 与历史方案的关系

前一阶段已经停止把堵塞风险预测器或当前堵塞检测器作为反事实行为段的主边界。相关原因见
[风险预测器到堵塞检测器阶段复盘](../../development_tracks/01_pair_risk_to_blockage/README.md)。
本模块不继续修补该检测机制，而是从“当前结构还保留哪些合成路径”重新定义观察量。
