# 内部升级路径

- 状态：**方向已确认；等级代价仍待讨论**

## 基本语义

内部路径表示：不依赖顶部立即送来一个完整同级伙伴，当前局部已有水果是否能逐步升级，形成
一个有机会与目标合成的同级水果。

## 第一版递推规则

1. 如果局部邻域已经存在同级水果，把它视为直接合成终点，内部难度最低；
2. 否则只考察等级不高于目标的候选；
3. 优先使用等级最接近目标的低等级候选；
4. 候选自身的可合成性表示它继续升级的容易程度，再叠加从其等级传递到目标等级所需的
   简单代价；
5. 多个候选暂时只保留少量最佳路径，并以最容易的一条作为内部结果。

“等级最接近”指等级差最小，不是欧氏距离最近。几何距离已经由局部邻域完成定性筛选，不再
进入等级传递代价。

## 等级传递难度

已确认的约束：

- 随等级差增大而增大；
- 只使用少量离散档位或同等简单的单调规则；
- 不混入距离、速度、危险线等量纲不同的连续量；
- 应反映多级升级需要更多材料，不能默认每差一级都具有完全相同的资源难度。

尚未确认：

- 采用线性、按资源倍增近似，还是人工离散表；
- 不同等级段是否使用相同代价；
- 难度如何映射到最终的零到一连续分数。

## 防止循环依赖

同级水果一旦满足局部关系，就作为终点，不再互相读取对方的可合成性。只有低等级候选可以
继续依赖更低等级候选。这样依赖沿等级单向下降，计算时再从低等级向高等级回填，可以避免
同级水果互相引用形成循环。

## 第一版明确不解决的问题

- 不严格核算从低级水果升级到目标等级所需的全部水果数量；
- 不解决两个目标同时占用同一材料的冲突；
- 候选水果完成自身合成后，结果圆可能向远离目标的一侧偏移；第一版只根据当前候选是否位于
  目标邻域近似其局部相关性，不保证升级产物仍留在目标附近；
- 不证明路径一定会在真实物理和后续策略下执行成功；
- 不因为局部候选很多就简单累加分数，防止水果数量直接淹没路径质量。

因此内部结果应被解释为“当前最有希望的局部升级链”，而不是完整可执行计划。

如果人工观察确认“升级产物偏移”造成大量高估，下一版可以利用项目已有的配对最低结果圆
几何，对候选升级后的结果位置做定性过滤。这个过滤目前只是切换候选，不进入第一版。
